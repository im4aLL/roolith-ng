Switch

A toggle switch built as rng-switch-input. Supports label, hint, validation state via error and errorMessage, plus FormValueControl<boolean> integration for signals forms. The switch state is exposed as boolean via [(value)] and (checkedChange).

Import

Usage

Basic

Provide label for the text beside the toggle. Use two-way binding [(value)] to sync the on/off state. The model is boolean with default false (off).

Value: {{ basicValue() }}

Label and hint

Use label for the text rendered via rng-input-switch__text and hint for helper text below the switch via rng-input__hint. When label is null no text is shown. The hint is resolved via the computed hintMessage() which also handles errorMessage.

Without label No label - only the track and thumb are rendered.

Label: {{ labelValue() }} | Hint (off): {{ hintValue() }} | Hint (on): {{ hintValue2() }} | No label: {{ noLabelValue() }}

Hint vs error

Set [error]="true" to apply error styling via rng-input--error. When errorMessage is provided it overrides hint in the hint area via the computed hintMessage().

Use errorMessage to replace the hint when invalid - otherwise hint is shown. Error only: {{ errorValue() }} | Hint + error: {{ hintErrorValue() }}

States

Use [disabled]="true" to disable interaction via rng-input--disabled and native [disabled], [readonly]="true" to make it read-only, [required]="true" for ARIA required via aria-required, and name to set the native name attribute. The component also reflects aria-invalid when invalid() is true.

Disabled: {{ disabledValue() }} | Disabled checked: {{ disabledCheckedValue() }} | Read-only: {{ readonlyValue() }} | Required: {{ requiredValue() }} | Name: {{ nameValue() }} (name="notifications")

Two-way binding and checkedChange

Bind [(value)] for two-way sync or listen to (checkedChange) for explicit handling. The value model is a model<boolean> - toggling calls onChange which sets value and emits checkedChange, blurring marks touched as true.

Current: {{ twoWayValue() }}

With FormField (signals forms)

rng-switch-input implements FormValueControl<boolean> and can be bound to a signals form via [formField]. The component syncs value, disabled, required, invalid, touched and validation state from the form.
