Use only what you need

Each component is a standalone import with no global registration. Tree-shaking removes everything you do not use.

  • Per-component imports
  • No NgModule - works with standalone APIs
  • Consistent props and design tokens

Install in seconds

Requires Angular 21+ (>=21.0.0). No extra setup for forms or theming.

  • Tree-shakable - import only what you use
  • Works with standalone components
  • Runtime deps: lodash-es, luxon, tslib
