File Input

A styled file upload field built as rng-file-input. Supports single and multiple file selection, accept filters for MIME types or extensions, and FormValueControl<File[]> integration for signals forms. Selected files are exposed as a File[] model via [(value)] and (fileChange).

Use accept to restrict selectable files. It accepts a comma-separated list of MIME types or extensions such as .pdf, .jpg,.png or image/*. The value is forwarded to the native [accept] attribute on <input type="file">.

Hint

Provide hint to show helper text below the field via rng-input__hint. The hint is visible when not overridden by an error message.

Files: {{ hintFiles().length }}

Error state

Set [error]="true" to apply error styling via rng-input--error. When errorMessage is provided it overrides hint in the hint area via the computed hintMessage().

Use errorMessage to replace the hint when invalid - otherwise hint is shown. Current: {{ errorFiles().length > 0 ? errorFiles()[0].name : 'none' }}

States

Use [disabled]="true" to disable the field via rng-input--disabled, [required]="true" for ARIA required via aria-required, and name to set the native name attribute. The component also reflects aria-invalid when invalid() or error() is true.

Required: {{ requiredFiles().length }} file(s) | Name: {{ nameFiles().length }} (name="attachment")

Two-way binding and fileChange

Bind [(value)] for two-way sync or listen to (fileChange) for explicit handling. The value model is a model<File[]> with fileChange as its change output alias. Selecting files via the native picker calls onFileChange which sets value, marks touched as true and emits fileChange.

Current: {{ twoWayFiles().length }} file(s) @if (twoWayFiles().length > 0) { - @for (file of twoWayFiles(); track file.name) { {{ file.name }}@if (!$last) { , } } }

With FormField (signals forms)

rng-file-input implements FormValueControl<File[]> and can be bound to a signals form via [formField]. The component syncs value, disabled, required, invalid, touched and validation state from the form.
