Accordion

A vertically stacked set of interactive headings that each reveal a section of content. Only one item is expanded at a time by default - use allowMultiple to keep multiple items open, and bordered for a framed variant.

Import

Usage

Basic

The simplest accordion - the first item is auto-expanded on init when no item has [expanded]="true".

Content of item 1. Content of item 2. Content of item 3.

Bordered

Add a border and radius around the group with [bordered]="true".

Content of item 1. Content of item 2.

Allow multiple items open

By default only one item can be expanded at a time. Set [allowMultiple]="true" to allow multiple items to be open simultaneously.

Content of item 1. Content of item 2.

Disabled item

A disabled item cannot be expanded or collapsed. The header remains visible but ignores clicks.

Content of item 1. This item cannot be toggled.

Pre-expanded item

Control the initial state with [expanded]="true" on an rng-accordion-item. Two-way bindable via [(expanded)].

Content of item 1. This item starts expanded.

Listening to change events

changeEvent on rng-accordion fires whenever any item is toggled and provides the index, header and expanded state of the affected item.

Last event

expanded: {{ lastEvent.expanded }} • itemIndex: {{ lastEvent.itemIndex }} • itemHeader: "{{ lastEvent.itemHeader }}"

}

API

rng-accordion Inputs

InputTypeRequiredDefaultDescription
borderedbooleanNofalseAdds a border and border-radius around the accordion
allowMultiplebooleanNofalseWhen true, multiple items can be expanded at once

rng-accordion Outputs

OutputTypeDescription
changeEventOutputRef<IAccordionEvent>Emits whenever any child item is toggled, with its index, header and state

IAccordionEvent

PropertyTypeDescription
expandedbooleanWhether the item was expanded or collapsed
itemIndexnumberZero-based index of the toggled item
itemHeaderstringHeader text of the toggled item

rng-accordion-item Inputs

InputTypeRequiredDefaultDescription
headerstringNo''Text displayed in the clickable header row
disabledbooleanNofalseWhen true, the item cannot be expanded or collapsed
expandedbooleanNofalseTwo-way bindable. Controls the expanded state of the item

rng-accordion-item Outputs

OutputTypeDescription
changeEventOutputRef<boolean>Emits the new expanded state whenever it changes
