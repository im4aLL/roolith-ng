Toast

A succinct message that is displayed temporarily. Use ToastService with rng-toast for lightweight, non-blocking feedback. Supports success, error and info variants, an optional custom title and a fully custom IToast via show(). Toasts auto-dismiss after 5 seconds with a 300ms closing animation, a maximum of 3 toasts are visible at once and older ones are dropped when the limit is reached. Place <rng-toast /> once in your root layout and trigger toasts from any component or service.

Import

Setup

Host

Place <rng-toast /> once in your root layout template. The host reads ToastService.items() and renders the stack in rng-toast at the bottom-right. Without the host, calls to ToastService.success() / error() / info() will update the signal but nothing will appear. The host also provides a Clear button in rng-toast__close that calls ToastService.clear().

Injecting the service

Inject ToastService in any component or service to trigger toasts imperatively. The service is providedIn: 'root' so no extra provider is needed.

Usage

Success toast

Call toastService.success(message, title?) to show a success toast. When no title is provided it defaults to 'Success'. The item renders with rng-icon--check in rng-toast__icon and the title in rng-toast__content-hl.

Custom toast via show()

Call toastService.show(toast: IToast) to show a fully custom toast object. Provide type, title and message. Internally show() assigns _id via uniqueId(), prepends the item and slices to _maxItems (3).

Dismiss all toasts

Call toastService.clear() to dismiss all active toasts immediately. It clears the items signal and cancels any pending auto-remove timeouts. Each toast also has a Clear button in rng-toast__close that calls the same method.

Add toast Clear all

Auto-dismiss and stacking limit

Each toast auto-dismisses after 5 seconds (_timeoutDuration = 5000). On timeout the service first sets _isClosing = true which adds is--closing for the exit animation, then removes the item after 300ms (_closingAnimationDuration). A maximum of 3 toasts are shown at once - show() prepends and slices to _maxItems so older toasts are dropped. The stacking is styled via rng-toast__item:nth-child(1..3) positions.

Styling and behavior notes

The host renders rng-toast fixed at bottom: var(--rng-toast-padding) and right: var(--rng-toast-padding) with width: var(--rng-toast-width) (22.5rem). Each item is rng-toast__item with a border, shadow and background: var(--rng-toast-background-color). The icon mapping is success -> rng-icon--check, error -> rng-icon--alert, info -> rng-icon--info in rng-toast__icon. The title is rng-toast__content-hl with color: var(--rng-toast-content-header-color) and body is rng-toast__content. Stacking uses :nth-child(1..3) offsets and :nth-child(n+4) { display: none } hides overflow. The closing animation toggles is--closing which triggers a fade/slide defined in _toast.scss. Customize appearance via CSS variables: --rng-toast-padding, --rng-toast-width, --rng-toast-border-color, --rng-toast-background-color and --rng-toast-shadow.
