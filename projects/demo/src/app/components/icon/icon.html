Icon

A lightweight wrapper that renders an icon via the rng-icon selector. Each built-in name maps to a generated rng-icon--<name> class whose artwork comes from the library SCSS (mask-image). Supports three predefined size values, a fixed width in pixels, an extra styleClass, and a custom mode for your own SVGs or third-party icon fonts.

Import

Usage

Basic icon

Provide a name from the IconNameType set. The component renders an <i> with rng-icon and rng-icon--<name> classes.

Sized icon

Use size to switch between 'small', 'default' and 'large'. 'small' adds rng-icon--small and 'large' adds rng-icon--large - default renders without a size modifier.

Fixed pixel width

Set [width] to an explicit number to control both width and height in pixels. The value is bound to style.width.px and style.height.px on the inner <i>. When null the icon uses its CSS-defined size.

With additional CSS class

Pass styleClass to append extra class(es) to the icon element alongside rng-icon, the name class and the optional size class. Useful for color overrides, spacing or custom styling.

Custom and third-party icons

The built-in name maps to a generated rng-icon--<name> class whose artwork comes from the library SCSS (mask-image).

For icons that live outside the library (your own SVGs, or a third-party icon font such as Font Awesome), pass [custom]="true" and supply the class(es) yourself. In custom mode the base rng-icon class is omitted, so the library mask/background styling does not interfere with glyph fonts.

Custom icons require [custom]="true" - the base rng-icon class is omitted so the vendor font CSS controls rendering. Iconoir is already loaded globally via index.html; Font Awesome is loaded on this page via CDN for the demo (see snippet below).

Heads up

In custom mode the name is used as-is for the class attribute - no rng-icon prefix is added. For Font Awesome style usage pass the full list, e.g. name="fa-solid fa-user" or name="iconoir-home". For your own SVG, create a matching SCSS rule .rng-icon--<your-name> as shown above.

Styling notes

Each built-in icon is styled via SCSS mask-image (see rng-icon--<name> in the library). For custom SVG icons add the SCSS rule shown above. In custom mode the base rng-icon class is omitted to avoid mask/background interference with font glyphs.
