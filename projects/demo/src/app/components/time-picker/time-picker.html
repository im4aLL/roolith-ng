Time Picker

A 12-hour time picker built as rng-time-picker-input. Uses Luxon DateTime as the value type and exposes hour, minute and AM/PM selection via two rng-select-plain fields and a rng-button-group. Supports FormValueControl integration for signals forms. When hour or minute is empty the value is null.

Import

Usage

Basic

Provide label and optionally hint. Bind the selected time with two-way [(value)] - the model type is DateTime | null. The picker shows two selects for hours (01-12) and minutes (00-59) plus an AM/PM toggle.

Selected: {{ basicTime()?.toFormat('hh:mm a') ?? 'null' }} @if (basicTime()) { ({{ basicTime()?.toFormat('HH:mm') }}) }

Placeholder

Use placeholder to configure placeholder text for the field. The value is stored via the placeholder input and can be used for native semantics or future display handling.

Value: {{ placeholderTime()?.toFormat('hh:mm a') ?? 'null' }}

Hint

Provide hint to show helper text below the field via rng-input__hint. The hint is visible when not overridden by an error message.

Value: {{ hintTime()?.toFormat('hh:mm a') ?? 'null' }}

Error state

Set [error]="true" to apply error styling via rng-input--error. When errorMessage is provided it overrides hint in the hint area via the computed hintMessage().

Use errorMessage to replace the hint when invalid - otherwise hint is shown.

States

Use [disabled]="true" to disable the field via rng-input--disabled, [required]="true" for ARIA required, and name to set the native name attribute.

Disabled: {{ disabledTime()?.toFormat('hh:mm a') ?? 'null' }} | Required: {{ requiredTime()?.toFormat('hh:mm a') ?? 'null' }} | Name: {{ nameTime()?.toFormat('hh:mm a') ?? 'null' }} (name="startTime")

12-hour time selection

The field renders two rng-select-plain controls for hours (01-12 with an empty option value: -1) and minutes (00-59 with empty) plus a rng-button-group for AM/PM via hourFormats(). An internal effect merges selectedHour, selectedMinute and selectedHourFormat into value using 12-hour to 24-hour conversion (PM && hour !== 12 -> hour + 12, AM && hour === 12 -> 0). If hour, minute or format is missing the effect sets value to null. The display value is stored as DateTime.fromObject({{ '{' }} hour, minute {{ '}' }}).

12h: {{ basicTime()?.toFormat('hh:mm a') ?? 'null' }} | 24h: {{ basicTime()?.toFormat('HH:mm') ?? 'null' }} | ISO: {{ basicTime()?.toISOTime() ?? 'null' }}

Try 12:00 AM -> 00:00, 12:00 PM -> 12:00, 03:00 PM -> 15:00.

Pre-set value

When [value] is bound externally, the pickers initialize in ngOnInit via _setValueFromInitialDateTime(). The hour is converted to 12-hour format (hour % 12 === 0 ? 12 : hour % 12), minutes are zero-padded and selectedHourFormat is set to AM or PM.

Morning: {{ presetTime()?.toFormat('hh:mm a') ?? 'null' }} ({{ presetTime()?.toFormat('HH:mm') ?? '' }}) | Afternoon: {{ presetAfternoon()?.toFormat('hh:mm a') ?? 'null' }} ({{ presetAfternoon()?.toFormat('HH:mm') ?? '' }})

Two-way binding and valueChange

Bind [(value)] for two-way sync or listen to (valueChange) for explicit handling. The value model is a model<DateTime | null> with an associated valueChange output. Changing hour, minute or AM/PM triggers the internal effect which updates value - when a part is cleared the value becomes null.

Current value: {{ twoWayTime()?.toFormat('hh:mm a') ?? 'null' }} @if (twoWayTime()) { ({{ twoWayTime()?.toISOTime() }}) }

With FormField (signals forms)

rng-time-picker-input implements FormValueControl<DateTime | null> and can be bound to a signals form via [formField]. The component syncs value, disabled, required, invalid, touched and validation state from the form.

Resetting the value

Reset the model to null to clear the field. Clearing hour or minute (empty option) also sets value to null via the effect. The component marks touched as true on blur.
