Button Group

Renders a set of toggle buttons where one can be active at a time. Provide a list of labels and control the selected item with activeLabel. The active button receives rng-button--active and selection is reported via labelSelected. An optional size input mirrors the button sizes.

Import

Usage

Basic

Pass an array of strings to [labels] and bind the currently active value to [activeLabel]. Handle labelSelected to update the active state.

Sizes

Use size to scale the group. Accepts 'xsmall', 'small', 'large' and 'default'. The value maps to rng-button-group--<size> and rng-button--<size> on the inner buttons.

Listening to selection

labelSelected emits the clicked label as a string. The component calls event.preventDefault() internally before emitting.

Active label

labelSelected: "{{ activeTab }}"

}
