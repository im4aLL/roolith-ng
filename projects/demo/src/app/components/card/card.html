Card

A container for grouping related content with an optional header, subtitle, header action and footer. Use header and subheader for the title area, project a button or link with [rngCardAction] to the right of the header, and add actions at the bottom via [rngCardFooter]. The default slot renders inside rng-card__body.

Import

Or import individually if you prefer:

When projecting a header action or footer, also import CardActionDirective and CardFooterDirective. The card only renders rng-card__action and rng-card__footer when the corresponding directive content is present. Use IMPORT_CARD to import all three at once, or import them individually if you prefer.

With footer

API

rng-card Inputs

InputTypeRequiredDefaultDescription
headerstring | nullNonullTitle rendered in the card header
subheaderstring | nullNonullSubtitle rendered below the title

rng-card Content Projection

SlotSelectorDirectiveDescription
Body (default)(default)-Main content of the card, rendered inside rng-card__body
Header action[rngCardAction]CardActionDirectiveElement placed on the right side of the card header inside rng-card__action. Wrapper only renders when directive is present
Footer[rngCardFooter]CardFooterDirectiveContent rendered inside rng-card__footer at the bottom of the card. Wrapper only renders when directive is present

Directives

DirectiveSelectorDescription
CardActionDirective[rngCardAction]Marker for header action projection. Detected via contentChild(CardActionDirective)
CardFooterDirective[rngCardFooter]Marker for footer projection. Detected via contentChild(CardFooterDirective)

IMPORT_CARD

Includes CardComponent, CardActionDirective and CardFooterDirective.
