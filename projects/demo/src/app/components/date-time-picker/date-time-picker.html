Date Time Picker

A combined date and time picker built as rng-date-time-picker-input. Combines a calendar date picker and a 12-hour time selector into a single field - selecting a date closes the popover while time is adjusted inline in the same panel. Uses Luxon DateTime as the value type and supports FormValueControl integration for signals forms. When only a date is selected and no time has been chosen, the value defaults to midnight (00:00).

Usage

Basic

Provide label and placeholder. Bind the selected date and time with two-way [(value)] - the model type is DateTime | null. Click the field to open the popover with rng-calendar and time controls. Selecting a date closes the popover; adjust hours, minutes and AM/PM inline without reopening.

Time selection

The popover contains a rng-calendar for the date and inline time controls: two rng-select-plain fields for hours (01-12) and minutes (00-59) plus a rng-button-group for AM/PM. Picking a date in the calendar calls onCalendarValueChange, sets calendarValue, marks touched and closes the popover. Time changes call onChangeHour, onChangeMinute or onChangeHourFormat and are merged into value via an effect that applies 12-hour to 24-hour conversion. If no hour or minute is selected (empty option with value: -1), the value defaults to midnight (date.startOf('day')).

Time defaults to 00:00 until you choose hour and minute - check the ISO output after picking only a date vs date + time.

Field label: {{ basicDateTime()?.toLocaleString(DateTime.DATETIME_MED) ?? 'null' }}

Pre-set value

When [value] is bound externally, both the calendar and the time selectors initialize from it in ngOnInit via _initFromValue(). The date part is stored in calendarValue as startOf('day') and the time part sets selectedHour, selectedMinute and selectedHourFormat (12-hour conversion).

Pre-set: {{ presetDateTime()?.toISO() ?? 'null' }} ({{ presetDateTime()?.toLocaleString(DateTime.DATETIME_MED) ?? '' }})

Two-way binding and valueChange

Bind [(value)] for two-way sync or listen to (valueChange) for explicit handling. The value model is a model<DateTime | null> with an associated valueChange output. Selecting a date or changing time triggers the internal effect which updates value - when time is incomplete the value is the date at midnight.

Current value: {{ twoWayDateTime()?.toISO() ?? 'null' }}

With FormField (signals forms)

rng-date-time-picker-input implements FormValueControl<DateTime | null> and can be bound to a signals form via [formField]. The component syncs value, disabled, required, invalid, touched and validation state from the form.

Resetting the value

Reset the model to null to clear the field. Both calendarValue and the time selectors will reflect the cleared state on next open; the effect will keep value as null until a new date is picked.
