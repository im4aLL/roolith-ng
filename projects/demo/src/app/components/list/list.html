List

rng-list renders an unordered list from a structured array of items. Each entry is an IListItem with required content and optional title. When title is present it is rendered as a header above the content inside rng-list__item.

Import

Usage

Basic

Pass an array of IListItem to [items]. Each item only needs content - the list renders a plain <ul class="rng-list"> with rng-list__content inside each rng-list__item.

With titles

When title is provided it renders as a header above the item content inside rng-list__header. The title is also used as the tracking key for @for - items without a title fall back to the array index.

Mixed content

Mix titled and plain items in the same list. Only items with a title render the header element - others show just the content.

Full example

Plain and titled items together, covering the typical use case.

API

rng-list Inputs

InputTypeRequiredDefaultDescription
itemsIListItem[]No[]Array of items to render as <li> elements inside rng-list

IListItem

PropertyTypeRequiredDescription
contentstringYesMain text displayed inside the list item (rng-list__content)
titlestringNoHeader shown above content inside rng-list__header. Also used as the tracking key for @for when present, otherwise the index is used

Tracking

The component transforms items internally and assigns _trackBy as title ?? index. Duplicate titles will share the same track key - prefer unique titles or omit the title when uniqueness cannot be guaranteed.
