Select

A single-value dropdown select built as rng-select-input. Supports search filtering, keyboard navigation, typeahead, a clear button, custom option templates, and FormValueControl<ISelectInput | undefined> integration for signals forms. The selected value is a single ISelectInput model via [(value)].

Import

ISelectInput

Each option has a label for display and a value for identity. Optional icon and subtext are available for custom templates and the default template.

Usage

Basic

Provide [data], label and placeholder. Bind [(value)] for two-way sync - value is a model<ISelectInput | undefined>. Clicking the field calls onInputFocusHandler() which shows focus and the dropdown via isActive(). Selecting an option calls onSelectHandler(item) which sets value and clears inputValue.

@if (basicSelected()) { Selected: {{ basicSelected()!.label }} ({{ basicSelected()!.value }}) } @else { No selection - open the dropdown and pick a country. }

Searchable (filtering)

Set [searchable]="true" to render a text <input> that filters options. The list is derived via the filteredData computed which does a case-insensitive label.includes() on inputValue(). When searchable is false the component instead buffers keystrokes and focuses the first matching option (typeahead, 300ms debounce) via _watchForTypeahead. Changing the input calls onInput(value) which updates inputValue(); on change it tries an exact label match via onChange(value).

@if (searchableSelected()) { Selected: {{ searchableSelected()!.label }} } @else { Type inside the field to filter - e.g. ger or ca. }

With clear button

Set [showClear]="true" to show a clear button when a value is selected. Visibility is derived via isShowClearButton() (showClear() && !!value()). Clicking it calls onClear($event) which stops propagation, clears value to undefined, resets inputValue and re-focuses the field via showFocus().showOptions().

@if (showClearSelected()) { Selected: {{ showClearSelected()!.label }} - click the rng-icon--delete clear button to reset. } @else { Pick a country - the clear button appears only when a value is selected via [showClear]="true". }

Hint

Provide hint to show helper text below the field. It renders via hintMessage() when not overridden by an error.

Selected: {{ hintSelected() ? hintSelected()!.label : 'none' }}

Error state

Set [error]="true" to apply error styling via rng-input--error. When errorMessage is provided it overrides hint in the hint area via the computed hintMessage().

Use errorMessage to replace the hint when invalid - otherwise hint is shown. Current: {{ errorSelected() ? errorSelected()!.label : 'none' }}

Custom option template

Use #rngSelectInputOptionTemplate with let-item to customize each option row. By default it renders item.icon as <i [class]="item.icon"> with the label and a check when selected. For richer rows, wrap the content in rng-input-list__item-content with rng-input-list__item-content-hl and rng-input-list__item-content-body. For flags, put the CDN URL in icon (e.g. https://flagcdn.com/w20/us.png) and render it as <img [src]="item.icon">.

{{ item.label }} @if (item.subtext) { {{ item.subtext }} }
@if (customSelected()) { Selected: {{ customSelected()!.label }} - {{ customSelected()!.subtext }} } @else { Each row shows a CDN flag (https://flagcdn.com/w20/<code>.png in icon) + label + subtext stacked via rng-input-list__item-content. }

States

Use [disabled]="true" to disable the field via rng-input--disabled and native [disabled], [readonly]="true" for read-only (input is readonly when readonly() || !searchable()), [required]="true" for ARIA required via aria-required, [rightAligned]="true" to align the dropdown to the right edge via rng-input-list--right, [dropdownWidth] to set width in pixels on the list via [style.width.px], and name to set the native name attribute.

Right aligned: {{ rightAlignedSelected() ? rightAlignedSelected()!.label : 'none' }} | Width 320: {{ dropdownWidthSelected() ? dropdownWidthSelected()!.label : 'none' }} | Name: {{ nameSelected() ? nameSelected()!.label : 'none' }} (name="country")

Two-way binding and valueChange

Bind [(value)] for two-way sync or listen to (valueChange) for explicit handling. The value model is a model<ISelectInput | undefined>. Selecting an option sets value and hides the list via hideOptions(); clearing via onClear sets it to undefined.

Current: {{ twoWaySelected() ? twoWaySelected()!.label + ' (' + twoWaySelected()!.value + ')' : 'undefined' }}

Keyboard and overlay behavior

Click the field or press Enter to open the dropdown.

When open, use ArrowUp and ArrowDown to move through options and Escape to close. Press Enter or Space to select the focused option. Clicking outside also closes the dropdown.

If there is not enough space below, the list opens above the field automatically.

With FormField (signals forms)

rng-select-input implements FormValueControl<ISelectInput | undefined> and can be bound to a signals form via [formField]. The component syncs value, disabled, required, invalid, touched and validation state from the form.
