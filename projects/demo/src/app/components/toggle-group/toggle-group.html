Toggle Group

A segmented control that renders a list of buttons where one item can be active at a time. Provide items as IToggleGroupItem[], control the selected item with value (string | number | null) and listen to valueChange. Supports vertical and block (full-width) layouts via rng-toggle-group--vertical and rng-toggle-group--block. The active item receives rng-toggle-group__item--active where item.value === value().

Usage

Basic

Pass items and bind the currently active value to [value]. Handle (valueChange) to update your signal - the payload is the clicked IToggleGroupItem. The component is stateless and simply emits via selectItem(item) - the parent owns the active state.

IToggleGroupItem

Each entry in items follows the IToggleGroupItem interface. value can be a string or number - the active check uses strict equality item.value === value() inside toggle-group.component.html.

Value binding

value defaults to null - when null no item has rng-toggle-group__item--active. Use a string, number or null to control the active item. The button for the matching item is the only one with the active class.

Vertical

Set [vertical]="true" to stack items vertically. This adds rng-toggle-group--vertical to the container via containerClasses().

Block (full-width)

Set [block]="true" to stretch the group to full width with equal-width items. This adds rng-toggle-group--block to the container via containerClasses().

Active: {{ blockValue() === null ? 'null' : blockValue() }} - container is 100% width, items share the space equally.

Vertical + Block

Combine [vertical]="true" and [block]="true" for a vertical full-width group. Both classes are applied together via containerClasses() which returns { 'rng-toggle-group': true, 'rng-toggle-group--vertical': vertical(), 'rng-toggle-group--block': block() }.
