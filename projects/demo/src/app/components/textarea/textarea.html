Textarea

A multi-line text input built as rng-textarea-input. Supports autoResize to grow with content, character count via showCharCount and maxLength enforcement, plus label, hint, placeholder, rows and FormValueControl<string> integration for signals forms. The current value is exposed as string via [(value)] and (valueChange) (empty string when empty).

Import

Usage

Basic

Provide label, optionally placeholder and hint. Use two-way binding [(value)] to sync the string value. When the field is empty the model is '' - otherwise the typed string.

Value: "{{ basicValue() }}" ({{ basicValue().length }} chars)

Placeholder

Use placeholder to show hint text when the value is ''. It is forwarded to the native placeholder attribute on <textarea>.

Description: "{{ basicValue() }}"

Feedback: "{{ placeholderFeedbackValue() }}"

Hint

Provide hint to show helper text below the field via rng-input__hint. The hint is visible when not overridden by an error message and lives inside the rng-input__textarea-footer alongside the character counter.

Value: "{{ hintValue() }}"

Error state

Set [error]="true" to apply error styling via rng-input--error. When errorMessage is provided it overrides hint in the hint area via the computed hintMessage().

Use errorMessage to replace the hint when invalid - otherwise hint is shown. Current: "{{ errorValue() }}"

States

Use [disabled]="true" to disable the field via rng-input--disabled and native [disabled], [readonly]="true" to make it read-only via [readonly], [required]="true" for ARIA required via aria-required, and name to set the native name attribute. The component also reflects aria-invalid when invalid() is true.

Read-only: "{{ readonlyValue() }}" | Required: "{{ requiredValue() }}" | Name: "{{ nameValue() }}" (name="description")

Rows

Use [rows] to set the initial number of visible rows. Default is 4. It maps directly to the native [rows] attribute on <textarea>. When [autoResize]="true" the manual resize handle is hidden via rng-input__field--textarea-autoresize.

Value: "{{ rowsDefaultValue() || 'empty' }}" ({{ rowsDefaultValue().length }} chars) | [rows]="8"

Value: "{{ rowsCompactValue() || 'empty' }}" | [rows]="2"

Character count

Set [showCharCount]="true" to display a live counter in the footer via rng-input__char-count. The counter reads from the computed charCount() which is value().length. It is also shown automatically when [maxLength] is set.

Value: "{{ showCharCountValue() }}" | Counter shows {{ showCharCountValue().length }} via charCount()

Max length

Use [maxLength] to enforce a hard character limit and display an x / max counter. Input is capped at this length in onInput via textarea.value.slice(0, max) and also via native [attr.maxlength]. The counter turns red via rng-input__char-count--limit when isAtLimit() is true (charCount() >= maxLength()).

Bio: "{{ maxLengthValue() || 'empty' }}" ({{ maxLengthValue().length }} / 500)

Summary: "{{ maxLengthSummaryValue() }}" ({{ maxLengthSummaryValue().length }} / 100) @if (maxLengthSummaryValue().length >= 100) { - at limit }

Try typing past the limit - additional characters are discarded. The footer shows rng-input__char-count with rng-input__char-count--limit when at limit.

Auto resize

Set [autoResize]="true" to make the textarea grow vertically to fit its content. Manual resize is disabled via rng-input__field--textarea-autoresize. In onInput the handler sets textarea.style.height = 'auto' then textarea.style.height = textarea.scrollHeight + 'px'.

Value: "{{ autoResizeValue() || 'empty' }}" ({{ autoResizeValue().length }} chars)

Type multiple lines to see the field expand. Compare with a fixed [rows]="4" field without autoResize.

Auto resize + Max length

Combine [autoResize]="true" with [maxLength] to get a growing field that still enforces a limit. The character counter and the isAtLimit() styling continue to work - the limit is enforced in onInput before resizing.

Value length: {{ autoResizeMaxLengthValue().length }} / 300 @if (autoResizeMaxLengthValue().length >= 300) { - at limit }

Two-way binding and valueChange

Bind [(value)] for two-way sync or listen to (valueChange) for explicit handling. The value model is a model<string> with default ''. Typing in the field sets value via onInput and blurring marks touched as true.

Current: "{{ twoWayValue() }}" ({{ twoWayValue().length }} chars)

With FormField (signals forms)

rng-textarea-input implements FormValueControl<string> and can be bound to a signals form via [formField]. The component syncs value, disabled, required, invalid, touched and validation state from the form.

Full example

Combining label, placeholder, hint, rows, autoResize, maxLength and live value display.

Description: "{{ fullDescriptionValue() || 'empty' }}" | Feedback: "{{ fullFeedbackValue() || 'empty' }}"

Bio: "{{ fullBioValue() || 'empty' }}" ({{ fullBioValue().length }} / 500) | Notes: "{{ fullNotesValue() || 'empty' }}" ({{ fullNotesValue().length }} chars)

Behavior notes

  • Typing updates value immediately via onInput - the native <textarea> value is bound with [value]="value()" and (input)="onInput($event)".
  • Blurring the field marks touched as true via (blur)="touched.set(true)".
  • The outer wrapper uses rng-input with rng-input--disabled and rng-input--error modifiers.
  • The footer rng-input__textarea-footer holds the hint and the character counter; when neither hintMessage() nor counter is present the counter area is still rendered as an empty <span> for layout.
  • Character counting uses charCount() and the limit styling uses isAtLimit() - when maxLength() is undefined the counter is only shown if showCharCount() is true.
  • Auto-resize sets rng-input__field--textarea-autoresize on the <textarea> to hide the manual resize handle; height is recalculated on every input event.
  • Validation via maxLength is a hard cap enforced in the component - it does not rely on native form validation.
