AI Ready - For AI Agents

@im4all/roolith-ng ships an installable agent skill so AI coding agents generate correct rng-* markup, imports, theming and forms code without guesswork. Opt-in, zero runtime cost - the skill is documentation your agent can read.

At a glance

Package installs the component library as usual with npm install @im4all/roolith-ng. Then add the roolith-ng skill to your agent so it uses bundled references/*.md docs for every component, not hallucinated props.

Why install the skill

Without the skill, agents often invent props, selectors or import paths. With it, they:

  • Import the exact standalone component from @im4all/roolith-ng via imports: [...].
  • Use correct rng-* selectors and signal variables.
  • Follow theming, forms and convention rules from AGENTS.md - rem(), Iconoir icons, no raw tag selectors.
  • Cite the doc's Inputs table instead of inventing props.

What the skill includes

The skill lives at skills/roolith-ng/SKILL.md:1 in this repo and is published inside the npm package under skills/roolith-ng/. It is copied to your project's agent directory on install - no symlink, no runtime dependency.

Install the library first, then add the skill with npx skills add. The installer detects your agents and copies to the right locations - Pi and OpenCode first, then others.

Usage - tell your agent

Once installed, prompt your agent with natural language. Include the roolith-ng trigger phrase:

More examples:

  • Add a roolith-ng card with a filter and table
  • Use roolith-ng dialog with DialogService
  • Create a form with roolith-ng text-input and select-input using ReactiveForms
  • Use rng-icon with name="search" from roolith-ng

The agent will read references/<name>.md from the installed skill, copy imports and selectors verbatim, and adapt the Usage snippet to your task.

Conventions your agent follows

The skill encodes project rules so the agent does not need to be told twice:

  • Selectors use rng-* prefix - e.g. <rng-button>, <rng-card>.
  • Standalone imports only - import {{ '{' }} ButtonComponent {{ '}' }} from '@im4all/roolith-ng' then imports: [ButtonComponent].
  • Icons via <rng-icon name="search"> with built-in IconNameType; Iconoir class names only with [custom]="true".
  • Signals over plain variables, and rem() via @use '@im4all/roolith-ng/sass/functions/rem' - never raw 1px.
  • No raw tag selectors in SCSS, no component SCSS for ad-hoc styling.
  • Generate components with ng g component <path> --project=<name>.

Updating

When you update the package with npm install @im4all/roolith-ng@latest, re-run the skill installer to refresh the copied docs. In this repo, the source of truth is projects/roolith-ng/src/lib/components/**/*.md - maintainers re-sync with cp into skills/roolith-ng/references/<name>.md (never ln -s).

Heads up

The published npm package does not ship *.md from node_modules sourcing - agents must read from the installed skill at .pi/skills/roolith-ng/references/, .opencode/skills/roolith-ng/references/ or .agents/skills/roolith-ng/references/, not from projects/roolith-ng/... in consumer projects.
