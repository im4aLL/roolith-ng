Date Picker

A date picker with a calendar popover built as rng-date-picker-input. Uses Luxon DateTime as the value type and opens a rng-calendar inside a native popover anchored to the field. Supports FormValueControl integration for signals forms.

Import

Usage

Basic

Provide label and placeholder. Bind the selected date with two-way [(value)] - the model type is DateTime | null. Click the field to open the calendar popover and pick a date.

Selected: {{ basicDate()?.toISODate() ?? 'null' }} @if (basicDate()) { ({{ basicDate()?.toLocaleString(DateTime.DATE_MED) }}) }

Placeholder

Use placeholder when no date is selected. The placeholder is shown inside rng-input__field--placeholder until a date is picked. Once a date is selected the formatted value replaces the placeholder.

Value: {{ placeholderDate()?.toISODate() ?? 'null' }}

Custom display format

Control how the selected date is displayed with [format] - a Luxon DateTimeFormatOptions object. Defaults to DateTime.DATE_MED (e.g. Jun 15, 2024). The field text is derived from calendarValue().toLocaleString(format()).

Numeric: {{ formatDate()?.toISODate() ?? 'null' }} | Long: {{ formatDateNumeric()?.toISODate() ?? 'null' }}

Hint

Provide hint to show helper text below the field via rng-input__hint. The hint is visible when not overridden by an error message.

Value: {{ hintDate()?.toISODate() ?? 'null' }}

Error state

Set [error]="true" to apply error styling via rng-input--error. When errorMessage is provided it overrides hint in the hint area via the computed hintMessage().

Use errorMessage to replace the hint when invalid - otherwise hint is shown.

States

Use [disabled]="true" to disable the field via rng-input--disabled, [required]="true" for ARIA required, and name to set the native name attribute.

Required: {{ requiredDate()?.toISODate() ?? 'null' }} | Name: {{ nameDate()?.toISODate() ?? 'null' }} (name="startDate")

Two-way binding and valueChange

Bind [(value)] for two-way sync or listen to (valueChange) for explicit handling. The value model is a model<DateTime | null> with an associated valueChange output. Selecting a date in the calendar calls onCalendarValueChange which sets both calendarValue and value and marks touched as true.

Current value: {{ twoWayDate()?.toISODate() ?? 'null' }}

With FormField (signals forms)

rng-date-picker-input implements FormValueControl<DateTime | null> and can be bound to a signals form via [formField]. The component syncs value, disabled, required, invalid, touched and validation state from the form.

Clearing the value

Call clearInput() via a template reference or reset the model to null. Both clear calendarValue and value, set touched to true and close the popover.
