Number Input

A numeric input field built as rng-number-input. Supports min, max and step constraints, validation state via error and errorMessage, plus label, hint, placeholder and FormValueControl<number | null> integration for signals forms. The current value is exposed as number | null via [(value)] and (valueChange) (null when empty).

Basic

Provide label and optionally placeholder. Use two-way binding [(value)] to sync the numeric value. When the field is empty the model is null - otherwise a number.

Hint

Provide hint to show helper text below the field via rng-input__hint. The hint is visible when not overridden by an error message.

Value: {{ hintValue() === null ? 'null' : hintValue() }}

Error state

Set [error]="true" to apply error styling via rng-input--error. When errorMessage is provided it overrides hint in the hint area via the computed hintMessage().

Use errorMessage to replace the hint when invalid - otherwise hint is shown. Current: {{ errorValue() === null ? 'null' : errorValue() }}

States

Use [disabled]="true" to disable the field via rng-input--disabled and native [disabled], [readonly]="true" to make it read-only via [readonly], [required]="true" for ARIA required via aria-required, and name to set the native name attribute. The component also reflects aria-invalid when invalid() or error() is true.

Read-only: {{ readonlyValue() === null ? 'null' : readonlyValue() }} | Required: {{ requiredValue() === null ? 'null' : requiredValue() }} | Name: {{ nameValue() === null ? 'null' : nameValue() }} (name="quantity")

Two-way binding and valueChange

Bind [(value)] for two-way sync or listen to (valueChange) for explicit handling. The value model is a model<number | null> - empty input emits null, non-numeric input is coerced to null via onInput. Typing in the field calls onInput which parses the raw string with Number(rawValue).

Current: {{ twoWayValue() === null ? 'null' : twoWayValue() }} ({{ twoWayValue() === null ? 'null' : typeof twoWayValue() }})

With FormField (signals forms)

rng-number-input implements FormValueControl<number | null> and can be bound to a signals form via [formField]. The component syncs value, disabled, required, invalid, touched and validation state from the form.
