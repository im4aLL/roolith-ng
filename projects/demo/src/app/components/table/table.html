Table

A responsive data table built as rng-table. Supports column definitions via ITableColumn, client-side sorting, built-in pagination, row selection with header select-all, free-text search, sticky columns and header, clickable and inline-editable cells with validation, expandable rows, per-column custom cell templates via rngTableCell, and a strategy-based export system for CSV, JSON or custom formats. The table is OnPush and auto-generates _trackKey for stable row tracking.

Import

Or import the full set of table pieces at once. IMPORT_TABLE includes TableComponent, TableSortComponent, TableHeaderCheckboxComponent, TableCheckboxComponent, TableStickyDirective, TableCellEditDirective and TableCellDirective.

Usage

Basic

Pass [data] as an array of ITableData and [columns] as ITableColumn[] with field and label. The component clones each row with a generated _trackKey and renders columnData derived from _setColumnData(). Without columns the table renders only the container and pagination.

Sortable columns

Mark columns as sortable via [sortableColumns] - an array of field strings that sets sortable: true on matching columnData entries. Provide [defaultSort] as ITableSortColumn to set the initial sortDirection. Click the header sort button to cycle asc -> desc -> default; onSortChange updates columnData and re-sorts via orderBy from lodash-es. When direction is default the original data() order is restored.

Heads up

Only one column is sorted at a time. When a new column is sorted, all other sortable columns reset to default. Non-sortable headers render plain text via columnLabel without rng-table-sort.

Paginated table

Enable [paginate] to render rng-pagination inside rng-table__pagination. Control rows per page with [perPage] (two-way bindable via [(perPage)] and typed as PageSizeOptionType) and visible page buttons with [maxPageItem]. Pagination slices items() into filteredItems() via _goToPage(); changing rowsPerPage resets to page 1 via _handleRowPerPageChange. When items().length <= perPage() the component skips slicing and keeps all rows visible.

Total {{ paginatedData().length }} rows - paginated at perPage 10, maxPageItem 5. Use the pagination footer to navigate.

Row selection

Set [allowSelection] to add a leading checkbox column with rng-table-header-checkbox and per-row rng-table-checkbox. The header checkbox watches body checkboxes via _watchHeaderCheckbox() and outputToObservable - clicking it sets every body fieldValue to the header value. Selection state is derived from _selectedRows and emitted via (selectionChange) with an effect. The indeterminate state is computed from _isAllChecked and _isSomeChecked.

@if (selectedRows().length > 0) { Selected {{ selectedRows().length }}: {{ selectedRows().length }} row(s) - check the header to select all. } @else { No rows selected - use the checkboxes or the header select-all. }

Column alignment and width

Use align ('left' | 'center' | 'right') and width (pixels) on ITableColumn. Width is bound to [style.minWidth.px] on <col> in the colgroup; alignment adds is--text-center or is--text-right on <th> and <td>. Selection and expand columns have fixed widths of 40px and no label.

Column with transform function

Set func on a column to derive the displayed value from the full row instead of row[field]. The function runs on every change detection cycle, so prefer pre-transforming data when possible for better performance. When func is present, editable and custom rngTableCell templates are ignored for that column.

Tip

Use func only when the transformation depends on multiple row fields (e.g. rate + rateType or rangeFrom - rangeTo). Otherwise map the data beforehand and bind the computed field directly.

Limit cell content

Set [limitCellContent]="true" to add rng-table--limit-cell-content on the table. Overflowing text is truncated with an ellipsis instead of wrapping - useful when columns have a fixed width and you want single-line rows.

Truncate cell content with tooltip

Set truncate on a column to cap text at maxContentLength characters and show the full value in an rng-tooltip on hover. Configure the tooltip via tooltipWidth and tooltipPosition (TooltipPositionType). In the default cell template the component checks content?.length > maxContentLength and renders content | slice: 0 : maxContentLength + '...' inside rng-tooltip.

Search filtering

Bind [searchTerm] to filter visible rows client-side across all fields via _getFilteredData (String(value).toLowerCase().includes(term)). On change the table calls _searchTermChanged() which filters data(), then re-applies sorting via _runSorting() and resets pagination with _resetPagination(). Clearing the term restores the original list via _init(). Pagination and selection are preserved.

Query: "{{ searchQuery() || '(empty)' }}" - matched {{ filteredCount() }} of {{ searchData().length }} rows.

Sticky columns

Pin the first N columns with [stickyConfig] (ITableStickyConfig). Provide numberOfColumns and a width array indexed to each sticky column; the component computes left offsets as a running sum of preceding widths and passes ITableStickyDirectiveData to [rngTableSticky] on every <th> and <td> via getStickyColumnDataByIndex(). Selection and expand columns count toward the sticky index.

The first two columns (ID and Name) stay pinned - scroll horizontally to see the effect. stickyConfig.width must match the rendered column widths for precise alignment.

Sticky header

Set [stickyHeader]="true" to pin the header while the body scrolls. The container gains is--sticky-header and its maxHeight (default '300px') constrains the scrollable area. maxHeight is required when sticky header is enabled - it is bound to [style.maxHeight] only when stickyHeader() is true.

Scroll the body - the header stays fixed at maxHeight 240px. Try with 400px for a taller viewport.

Editable cells

Set editable: true on a column to render cells as contenteditable="true" divs with rngTableCellEdit. On blur, onCellEdit() compares innerText.trim() with the old value; if unchanged it restores cellValue(oldValue) and returns. When valid and changed, it sets row[field] = newValue, flags row._isEdited = true so the row gains is--edited, stores data-previous-value on the cell, and emits (cellEditEvent) with ITableCellEditEvent. On focus, onCellFocus() clears the nullValuePlaceholder text when the underlying value is empty.

Validating edited values

Set editValidatorFn on the column to validate the new value before committing. The function receives string | number | null and must return true to accept. When it returns false, the cell gains rng-table__cell--edit-error and cellEditEvent is not emitted. Try entering 0 or -5 in the quantity column below - it will show the error state.

Quantity requires Number(value) > 0. Invalid edits keep the error class until a valid value is entered. Note: restrictCellEditToAlphanumeric and maxCellEditLength can be set per column to further constrain input.

Saving and discarding edits

Edited rows carry an internal _isEdited flag. Call saveEdits() to keep new values and clear the flag, or clearAllEdits() to revert every edited cell to its original data-previous-value and clear the flag plus the error class. Edits are stored in _cellEdits and re-synced after pagination via _syncCellEditsAfterPagination() inside a setTimeout.

Expandable rows

Set [expandableRows]="true" to add a leading toggle column with a rng-button variant="ghost" showing plus-square / minus-square. Clicking toggles expandedRowIndexes for that row index and renders #rngTableExpandedRow below the row in a spanning rng-table__expanded-row cell. The expanded template context exposes $implicit: ITableData, columns: ITableColumn[] and index: number. Without a template the default shows the row index.

Custom cell template

Use rngTableCell on an <ng-template> to override rendering for a specific column field. The directive input must match the column field. The template context exposes $implicit: unknown (row[field]), row: ITableData and field: string. It applies only to non-editable, non-func cells; multiple directives can be used together - one per field - and are collected via customCellTemplateData().

Custom no-record template

Provide #rngTableNoRecord to display custom content when filteredItems() is empty. Otherwise [noDataText] (default 'No records found') is shown in rng-table__no-data spanning all columns. The colspan accounts for selection: columnData().length + 1 when allowSelection is true.

Null placeholder and noDataText

Use [nullValuePlaceholder] to render a fallback for null, undefined or empty-string cells via cellValue(). Editable cells clear that placeholder text on focus via _clearPlaceholderText() so the user edits an empty field.

nullValuePlaceholder="-" shows - for empty note cells. With no placeholder, empty values render as ''.

Custom header, body and footer templates

Project #rngTableHeader, #rngTableBody or #rngTableFooter to override the respective table sections. #rngTableBody receives $implicit: ITableData, columns: ITableColumn[] and index: number; the header and footer receive no context by default. The footer renders inside <tfoot> only when footerTemplate() is present.

Export - CSV and JSON

The exporter is framework-agnostic. Instantiate TableExporter, call setStrategy() with a ITableExportStrategy, then either export(data, columns) to get a string or download(data, columns, filename) to trigger a browser <a> download. The strategy provides extension and mimeType. download() throws if no strategy is set, creates a Blob, generates an object URL, clicks a hidden anchor, then revokes the URL in a setTimeout.
