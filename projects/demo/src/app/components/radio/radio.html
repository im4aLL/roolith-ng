Radio

A group of radio buttons built as rng-radio-input. Supports options with IRadioOption, inline layout via inline, label, hint, validation state via error and errorMessage, plus FormValueControl<string | number | null> integration for signals forms. The selected value is exposed as string | number | null via [(value)] and (valueChange).

Import

Usage

Basic

Provide options as an array of IRadioOption. Use label for the group heading and hint for helper text. Bind [(value)] to sync the selected option - the model is string | number | null.

IRadioOption

Each entry in options follows the IRadioOption interface. value can be a string or number - comparisons are done with value() === option.value.

Inline layout

Set [inline]="true" to display options horizontally. By default (inline is false) options are stacked vertically via rng-input__field-wrapper--alt.

Selected size: {{ inlineValue() === null ? 'null' : inlineValue() }}

Stacked uses rng-input__field-wrapper--alt - inline removes it.

Label and hint

Use label for the group heading rendered via <label [for]="id() + '-0'"> and hint for helper text below the group via rng-input__hint. When label is null no heading is rendered.

Hint value: {{ hintValue() === null ? 'null' : hintValue() }}

Error state

Set [error]="true" to apply error styling via rng-input--error. When errorMessage is provided it overrides hint in the hint area via the computed hintMessage().

Use errorMessage to replace the hint when invalid - otherwise hint is shown. Current: {{ errorValue() === null ? 'null' : errorValue() }}

States

Use [disabled]="true" to disable all radios via rng-input--disabled and native [disabled], [required]="true" for ARIA required via aria-required, name to set a shared name attribute (defaults to id() when empty), and [inline]="true" for horizontal layout. The component also reflects aria-invalid when invalid() is true.

Numeric values

IRadioOption.value accepts both string and number. The template tracks options by option.value and compares with value() === option.value. On change, the component resolves the raw string via String(opt.value) === rawValue to restore the original type.

Two-way binding and valueChange

Bind [(value)] for two-way sync or listen to (valueChange) for explicit handling. The value model is a model<string | number | null> - selecting a radio calls onChange which matches String(opt.value) === rawValue and sets the typed value, blurring marks touched as true.

Current: {{ twoWayValue() === null ? 'null' : twoWayValue() }} ({{ twoWayValue() === null ? 'null' : typeof twoWayValue() }})

With FormField (signals forms)

rng-radio-input implements FormValueControl<string | number | null> and can be bound to a signals form via [formField]. The component syncs value, disabled, required, invalid, touched and validation state from the form.
