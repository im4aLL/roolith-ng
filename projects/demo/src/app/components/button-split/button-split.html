Button Split

A split button combining a content area (text / icon) with a separate action icon button that emits the click event. The text area is fully projected via <ng-content /> so any combination of plain text, <rng-icon> and <em> can be rendered. Use actionIcon to control the right-side button icon, size to scale the component and clickEvent to handle the action click.

Sizes

Use size to scale the component. 'xsmall' maps to rng-button-split--xsmall, 'small' to rng-button-split--small and 'large' to rng-button-split--large. The default value omits the modifier class.

Extra Small Small Default Large

Listening to click events

clickEvent is emitted with a void payload when the action icon button is clicked. The text area itself is non-interactive - only the right icon button triggers the output.
