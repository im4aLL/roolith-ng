Drawer

A panel that slides out from the edge of the screen. Uses the native popover API - wire any trigger element with [rngDrawerTarget] to the matching name of rng-drawer. Supports an optional header and subheader, body content via the default slot, and footer actions via [rngDrawerAction]. The header X button and Escape key both close the drawer and emit closeEvent.

Usage

Basic drawer

Place rngDrawerTarget="drawer1" on a trigger element and match it to the name of rng-drawer. The directive resolves the inner <button> element and sets the native popovertarget attribute automatically. Body content is projected into rng-drawer__body and the footer slot [rngDrawerAction] renders inside rng-drawer__footer.

Header and subheader

Provide header for the title and subheader for the subtitle. The header area rng-drawer__header renders rng-drawer__hl and optionally rng-drawer__subhl when subheader() is truthy.

Body content

Anything without a selector is projected into rng-drawer__body via <ng-content />. No content input is needed - just place markup inside the element.

Footer actions

Wrap footer buttons in <ng-container rngDrawerAction>. The content is rendered inside rng-drawer__footer. Use [block]="true" on buttons for full-width footer actions and call drawerEl.close() to dismiss from an action.

Trigger directive

[rngDrawerTarget] can be placed on rng-button or any element that contains a <button>. On init the directive finds the first clickable element and sets popovertarget="<name>" so the browser opens the matching popover with id="<name>".

Closing programmatically

Use a template reference (#myDrawer) and call .close() or .open(). Both delegate to the native hidePopover() / showPopover() on the drawer element. The close (X) button in the header also calls close() internally.

Reacting to open and close events

API

rng-drawer Inputs

InputTypeRequiredDefaultDescription
namestringNo'drawer'Unique name used to link the trigger. Rendered as id on the popover element and matched by [rngDrawerTarget] via popovertarget
headerstring | nullNonullTitle rendered in rng-drawer__hl inside rng-drawer__header-text
subheaderstring | nullNonullSubtitle below the header. Rendered in rng-drawer__subhl only when truthy

rng-drawer Outputs

OutputPayloadDescription
openEventvoidEmitted when the drawer opens - native toggle event with newState: 'open'
closeEventvoidEmitted when the drawer closes - whether via .close(), the X button, or Escape (toggle newState: 'closed')

rng-drawer Methods

MethodSignatureDescription
openopen(): voidOpens the drawer by calling showPopover() on the native element. No-op when the element ref is missing
closeclose(): voidCloses the drawer by calling hidePopover(). Called by the header X button and can be called from footer actions or component logic

rng-drawer Content Projection

SlotSelectorDescription
Body (default)(default)Main content of the drawer, rendered inside rng-drawer__body
Action footer[rngDrawerAction]Buttons or actions rendered inside rng-drawer__footer at the bottom of the drawer

rngDrawerTarget Directive

InputTypeDefaultDescription
