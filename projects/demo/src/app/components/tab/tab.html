Tab

A tabbed navigation component that uses a rng-toggle-group for the tab bar and renders the active pane's content. Provide parallel items and contents arrays matched by value / key, and optionally override any pane with a rngTabContentOf template.

Import

Usage

Basic (static content)

Pass items to drive the tab bar and contents to supply the body of each pane. Items are matched to content by value / key. The first item is selected by default when value is not set. Listen to (changeEvent) to react to tab changes.

ITabItem

ITabItem is an alias for IToggleGroupItem. Each entry drives one tab button in the bar.

ITabContent

Each entry supplies the body for one pane. key must match the corresponding ITabItem.value. When header is present it is rendered as rng-tab__hl above the body. Override per-pane rendering with rngTabContentOf.

Default selected tab

Pass value to pre-select a tab by its value. When value is null, undefined or does not match any item, the component falls back to the first item. You can use a static attribute value="tab-2" or a signal binding [value]="activeTab()" - in both cases the value is read only in ngOnInit.

Static value

Pre-selected via value="tab-2" - Tab 2 is active on load.

Signal binding (initial only)

Bound via [value]="activeTab()" where activeTab = signal('tab-1'). Updates to the signal after init do not re-select - track (changeEvent) instead.

Custom pane template

Use the rngTabContentOf directive on an <ng-template> inside rng-tab to override the rendered content for a specific tab key. The template receives the matching ITabContent object as $implicit - access it with let-item or let-tab (the local name is yours). Any pane without a custom template falls back to the default header + content rendering. The template can contain any markup or components - for example a rng-button.

{{ item.header }}
{{ item.content }}. This text indicates that this is a custom template for tab 2
Button in custom tab content

Only tab-2 uses a custom template - other tabs render the default header / content. The directive value rngTabContentOf="tab-2" must match ITabContent.key.

Multiple custom templates

Supply one <ng-template rngTabContentOf="..."> per tab you want to customize. The component collects all directives via contentChildren(TabContentOfDirective) into customTemplateData(). Panes without a matching key use the built-in default template.

Layout variants

rng-tab forwards layout inputs to the root and to the inner rng-toggle-group. vertical stacks the tab bar vertically, block makes the bar full-width, and flip flips the content position. These map to rng-tab--vertical, rng-tab--block and rng-tab--flip. All five combinations below are used in practice.

Numeric keys

Both ITabItem.value and ITabContent.key accept string | number. Use numbers when tab identity is numeric - matching is done with strict equality (===).

Listening to change events

changeEvent emits the newly selected ITabItem whenever the active tab changes. The component updates selectedItem internally before emitting, and the matching pane is shown via rng-tab__pane--active. Parent items do not need to be updated - just listen and sync your own signal if you need the value outside the tab.

@if (lastEvent) {

Selected: {{ lastEvent.label }} ({{ lastEvent.value }})

}
