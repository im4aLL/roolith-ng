Progress

An indicator for task completion. rng-progress renders a native <progress> element with an optional header that shows a label and a computed percentage. The percentage is derived from value and max as Math.round((value / max) * 100) and clamped to 0-100. The header is omitted from the DOM when both label is null and showValue is false.

Import

Usage

Basic

The default progress bar with a label. With max omitted the component uses 100, so [value]="70" renders as 70%. The header shows the label on the left and the percentage on the right inside rng-progress__header.

Custom max value

Set [max] to a custom maximum. The percentage is computed against this value - [value]="3" with [max]="10" renders as 30%. The native <progress> receives the same max and value attributes, and aria-valuemax reflects max.

Without label

Omit label to show only the percentage in the header. The label element (rng-progress__label) is not rendered, but rng-progress__value with the computed percentage remains. The <label> is bound to the generated id via [for] when present.

Without percentage value

Set [showValue]="false" to hide the percentage and show only the label. The header still renders with just rng-progress__label. Use this when the label alone is descriptive enough or the numeric progress is shown elsewhere.

Bar only

When label is null and [showValue]="false", the header row (rng-progress__header) is not rendered at all via @if (label() || showValue()). Only the native <progress class="rng-progress__bar"> is shown.

Clamping and edge cases

percentage is computed as Math.min(100, Math.max(0, Math.round((value / max) * 100))). Values below 0 clamp to 0% and values above max clamp to 100%. When max is 0 the computed returns 0 to avoid division by zero. The native <progress> still receives the raw value and max attributes.

Percentage display vs native value

The header percentage reflects the clamped and rounded result from percentage(). The <progress> element and aria-valuenow keep the raw value so assistive technology announces the actual value, not the clamped display. Fallback text inside <progress> also shows {{ '{{' }} percentage() {{ '}}' }}%.

Dynamic value (signal binding)

Bind a signal to [value] to update the bar reactively. The component uses input() and computed(), so any signal change re-computes percentage() and updates both the header and the native <progress>. Accessibility

The native <progress> includes aria-valuenow, aria-valuemin="0" and aria-valuemax for screen readers. The label is associated with the progress element via for / id using the generated id(). The percentage span has aria-live="polite" so updates are announced. Inside <progress> the fallback text {{ '{{' }} percentage() {{ '}}' }}% is shown for browsers that do not support the element.

Styling notes

The host renders rng-progress with rng-progress__header for the label row and rng-progress__bar for the native progress. The header is a flex layout with the label and percentage spaced apart. The bar is a native <progress> element - style it via rng-progress__bar and browser-specific pseudo-elements like ::-webkit-progress-bar and ::-webkit-progress-value if needed.
