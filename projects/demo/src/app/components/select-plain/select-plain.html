Select Plain

A lightweight native <select> wrapper built as rng-select-plain. Use it when a styled dropdown overlay is not needed - it renders the browser's native select with the shared label and hint layout. Supports label, hint / errorMessage, disabled, required and name, plus FormValueControl<ISelectPlainOption | undefined> integration for signals forms. The selected value is a single ISelectPlainOption via [(value)].

Import

ISelectPlainOption

Each option has a label for display and a value for identity. value can be a string or number - matched on change via strict equality or string coercion so 2 matches native "2".

Usage

Basic

Provide [data], label and hint. Bind [(value)] for two-way sync - value is a model<ISelectPlainOption | undefined>. Changing the native select calls onChangeHandler($event) which finds the matching option in data and sets value (or undefined when no match).

@if (basicSelected()) { Selected: {{ basicSelected()!.label }} ({{ basicSelected()!.value }}) } @else { No selection - open the native dropdown and pick a priority. }

Label

Use label to render a field label via <label [for]="id()"> above the select. When label is null no label is rendered. The id is auto-generated via uniqueId() but can be overridden with [id].

Current: {{ hintSelected() ? hintSelected()!.label : 'none' }}

Hint

Provide hint to show helper text below the select. It renders via the computed hintMessage() when not overridden by an error.

Selected: {{ hintSelected() ? hintSelected()!.label : 'none' }}

Error state

Set [error]="true" to apply error styling via rng-input--error. When errorMessage is provided it overrides hint in the hint area via the computed hintMessage().

Use errorMessage to replace the hint when invalid - otherwise hint is shown. Current: {{ errorSelected() ? errorSelected()!.label : 'none' }} / {{ hintVsErrorSelected() ? hintVsErrorSelected()!.label : 'none' }}

Number values

ISelectPlainOption.value accepts string | number. On change the component compares the native string value with option.value === value || `${{ "{" }}option.value{{ "}" }}` === `${{ "{" }}value{{ "}" }}` so numeric options match correctly.

Selected: {{ numericSelected() ? numericSelected()!.label + ' (' + numericSelected()!.value + ' - ' + typeof numericSelected()!.value + ')' : 'none' }}

States

Use [disabled]="true" to disable the field via rng-input--disabled and native [disabled], [required]="true" for ARIA required via aria-required, and name to set the native name attribute. The component also reflects aria-invalid when invalid() is true (signals forms).

Disabled: {{ disabledSelected()!.label }} | Required: {{ requiredSelected() ? requiredSelected()!.label : 'none' }} | Name: {{ nameSelected() ? nameSelected()!.label : 'none' }} (name="priority")

Two-way binding and valueChange

Bind [(value)] for two-way sync or listen to (valueChange) for explicit handling. The value model is a model<ISelectPlainOption | undefined>. Selecting an option sets value to the matched ISelectPlainOption; an unmatched value resets it to undefined. Blur marks touched as true via (blur)="touched.set(true)".

Current: {{ twoWaySelected() ? twoWaySelected()!.label + ' (' + twoWaySelected()!.value + ')' : 'undefined' }}

Change handling

The native <select> forwards change to onChangeHandler. Selected option is derived from [selected]="item.value === value()?.value" on each <option>.

With FormField (signals forms)

rng-select-plain implements FormValueControl<ISelectPlainOption | undefined> and can be bound to a signals form via [formField]. The component syncs value, disabled, required, invalid, touched and validation state from the form.
