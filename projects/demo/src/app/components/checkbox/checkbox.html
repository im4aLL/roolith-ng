Checkbox

A styled checkbox built as rng-checkbox-input. Supports a label via content projection, a standalone icon-only mode without a label wrapper, an indeterminate visual state that auto-clears when checked, and FormCheckboxControl integration for signals forms.

Project label text or rich HTML into the default slot. Use two-way binding [(checked)] to control the checked state.

Standalone (no label)

Set [standalone]="true" to render the checkbox without a label wrapper. Useful for table row selection or icon-only toggles. The component renders a self-closing element with no projected content.

Indeterminate state

Set [indeterminate]="true" to show the mixed state. The component adds is--indeterminate to the inner <input>. When checked becomes true, the indeterminate signal is automatically cleared to false.

States

Use [disabled]="true" to disable interaction, [error]="true" for error styling via rng-input--error, [required]="true" for ARIA required, and name to set the native name attribute.

Rich label content

The default slot accepts any HTML - links, <strong>, <em>, or other inline markup. Content is projected inside the rng-input-checkbox label next to the input.

Two-way binding and checkedChange

Bind [(checked)] for two-way sync or listen to (checkedChange) for explicit handling. The checked model is a model<boolean> with an associated checkedChange output.

With FormField (signals forms)

rng-checkbox-input implements FormCheckboxControl and can be bound to a signals form via [formField]. The component syncs checked, disabled, required and validation state from the form.

FormCheckboxControl integration

When used with signals forms, bind the field via [formField]="form.controls.*". The component implements FormCheckboxControl and syncs checked, disabled, required, invalid, touched and other control state.
