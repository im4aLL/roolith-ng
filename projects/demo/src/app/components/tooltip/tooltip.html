Tooltip

A wrapper that displays a tooltip relative to its trigger content on hover or focus. Provide plain text via text or rich markup through <ng-template #rngTooltipContent> - which automatically activates rng-tooltip--large mode. Position is controlled with position and the bubble width can be constrained with width.

Import

Usage

Basic - plain text

The simplest tooltip wraps any trigger content and shows text on hover or focus. When no position is set the bubble appears in the default placement and no modifier class such as rng-tooltip--top is added.

Position

Set position to 'top', 'bottom', 'left' or 'right' to control where the bubble appears. The component maps the value to rng-tooltip--top, rng-tooltip--bottom, rng-tooltip--left or rng-tooltip--right via the computed positionClassName. When omitted the bubble renders with no position class and falls back to the stylesheet default.

Custom width

Provide width as any CSS length string (e.g. "18rem", "220px", "20ch") to constrain the bubble. When set, the inner rng-tooltip__content receives rng-tooltip__content--limited and an inline max-width. Leave it null to let the content size naturally.

Wide (20rem) Narrow (12rem) Default

Rich content

For custom markup project an <ng-template #rngTooltipContent> as a content child instead of using text. When the template is present the component renders it via NgTemplateOutlet and adds rng-tooltip--large to the host. The fallback text interpolation is skipped entirely. Use the built-in helpers rng-tooltip__content-hl for a heading and rng-tooltip__content-button for a call-to-action.

API

rng-tooltip Inputs

InputTypeRequiredDefaultDescription
text string No '' Plain text to display inside the tooltip bubble. Ignored when #rngTooltipContent is projected
position 'top' | 'bottom' | 'left' | 'right' | undefined No undefined Position relative to the trigger. Maps to rng-tooltip--top / --bottom / --left / --right via positionClassName. No class when undefined
width string | null No null Optional inline width for the tooltip container. When set, adds rng-tooltip__content--limited and sets max-width via [style.maxWidth]

rng-tooltip Content Projection

SlotDescription
(default)The trigger element the tooltip wraps around - text, button, icon or any markup. Rendered via <ng-content /> inside rng-tooltip
#rngTooltipContent<ng-template> for rich or custom tooltip content. When present the component renders it via NgTemplateOutlet and adds rng-tooltip--large

TypeValuesDescription
TooltipPositionType'top' | 'bottom' | 'left' | 'right'Allowed values for position. Each maps to a rng-tooltip--<position> modifier class

Styling notes

The host renders as <div class="rng-tooltip"> with an optional position modifier from positionClassName and rng-tooltip--large when a content template is present. The bubble itself is rng-tooltip__content and receives rng-tooltip__content--limited plus an inline max-width when width is set. For rich tooltips use rng-tooltip__content-hl for a header and rng-tooltip__content-button for an action link inside the bubble.
