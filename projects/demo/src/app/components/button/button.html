Button

A button for triggering actions. Supports eleven color variant options, four size values, optional icon with iconPosition, a showLoading state that replaces the icon with a spinner and suppresses clickEvent, plus block for full-width layouts and disabled styling.

Import

Usage

Variants

The variant input controls the visual style. Defaults to 'default'.

Default Primary Secondary Success Danger Warning Info Dark Gray Ghost Link

Sizes

Use size to change the button scale. 'xsmall' maps to rng-button--xsmall, 'small' to rng-button--small and 'large' to rng-button--large.

Extra Small Small Default Large

With icon

Provide an icon from the IconNameType set. By default the icon appears on the left - set iconPosition="right" to move it to the right. Omit the projected label for an icon-only button.

Loading state

While [showLoading]="true" the click handler is suppressed, the icon (if any) is hidden and a spinner is shown. Useful for async actions such as saving.

Disabled

Set [disabled]="true" to style the button as disabled via rng-button--disabled. The native <button> still receives clicks through clickEvent unless combined with showLoading to suppress the handler.

Disabled Primary Disabled Ghost Disabled

Block (full width)

Set [block]="true" to make the button expand to its container width via rng-button--block.

Full Width Full Width Secondary

Click event

Listen to clickEvent - emitted on button click and automatically suppressed when showLoading is true. Provide an optional key to set an id on the inner <button>.
