Badge

A small label for status, counts or categories. Supports eight color type variants, two size options and a status layout that pairs an icon with the label. Use rng-badge-extended when you need supplementary text beside the badge.

Status variant

Set variant="status" with icon and iconColor to render a badge that represents a workflow state. The icon appears before the label text.

Extended badge - rich content

For custom markup, project an <ng-template #rngBadgeExtendedContent> instead of using text. The template content overrides the text input when both are present.
