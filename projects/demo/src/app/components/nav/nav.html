Nav

Two components for rendering navigation lists. rng-nav is a standalone list with optional submenu, badge and icon support. rng-nav-group wraps multiple named rng-nav sections and emits the group id together with the clicked item.

Usage

Basic

Pass an array of INav to [data]. Set isActive to mark the current route - the component adds rng-nav__item--focused to the active item. Clicking a leaf item emits clickEvent and updates the active state internally.

With submenu

Set children on an item to render a nested list inside rng-nav__sub-list. Clicking a parent item toggles its isOpen state and adds rng-nav__item--active. Parent items do not emit clickEvent - only leaf and child items do. Expand child items to set the parent and the clicked child as active.

With badge count

Set count on an item to display a badge via rng-badge next to the label. The same badge is mirrored inside the tooltip when [collapsed]="true". A falsy count (e.g. 0 or null) hides the badge.

With icons

Provide icon from the IconNameType set (e.g. 'home', 'settings'). The component renders rng-icon rng-icon--<name> inside rng-nav__item-icon - the artwork comes from the library SCSS mask.

With custom icons

Use customIcon for any vendor class string such as Iconoir (iconoir-home), Font Awesome (fa-solid fa-user) or your own font. The class is applied directly to rng-nav__item-icon without rng-icon - the SCSS rule rng-nav__item-icon:not(.rng-icon) handles sizing and color.

Collapsed mode

Set [collapsed]="true" to render the nav in compact mode - icons only with a tooltip on the right. The component adds rng-nav--compact and shows each item label inside rng-tooltip__content. In this mode opening one submenu automatically closes any other open submenu.

Listening to click events

clickEvent on rng-nav emits the clicked INav. Parent items with children are excluded - they only toggle isOpen. Child clicks also update the active state on both the child and its parent via childItemClickHandler. The component calls event.preventDefault() internally - handle routing in your callback.

Nav group

Use rng-nav-group to render multiple nav sections. Each group has its own name header, optional type and variation forwarded to its inner rng-nav, and items. When name is null the header is not rendered. The clickEvent payload is INavClickEvent with both item and groupId.

collapsedbooleanNofalseCompact icon-only mode with tooltip; opening one submenu closes others. Adds rng-nav--compact

OutputPayloadDescription

OutputPayloadDescription

INav

PropertyTypeRequiredDescription

namestringYesDisplay label rendered inside rng-nav__item-text
linkstringYesNavigation href for the anchor
isActivebooleanYesMarks the item as the currently active route - adds rng-nav__item--focused
countnumber | nullNoOptional badge count shown in rng-nav__item-badge and tooltip
iconIconNameType | nullNoBuilt-in icon name from IconNameType - renders rng-icon rng-icon--<name> inside rng-nav__item-icon
