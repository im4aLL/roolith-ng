Filter Button

A popover-driven filter control that lets users select one or more items from a searchable list. The trigger is a rng-button--filter that shows the active selection inline as rng-badge chips and a badge count when the selection exceeds maxSelectedItemsToShow. Selection state is emitted via changeEvent with a type of 'change' or 'clear'. Internally the popover contains an rng-search-input for filtering by label and a list of rng-checkbox-input rows with optional counter values.

Basic

Limiting inline badges with maxSelectedItemsToShow

[maxSelectedItemsToShow] controls how many selected labels are shown inline in the trigger. Defaults to 2. When selectedCount() > maxSelectedItemsToShow() the button collapses to a single rng-button__filter-item showing "{{ '{{' }} selectedCount() {{ '}}' }} selected". Otherwise each selected item is rendered as its own rng-badge separated by rng-button__filter-sep.

max = 1: Status
max = 2 (default): Status

Three items start selected - with max=1 you see "3 selected", with max=2 you also see "3 selected" (threshold exceeded). Deselect to 1 or 2 to see inline badges.

Search and clear

The popover header contains an rng-search-input that filters the list by label case-insensitively via onSearchInputChange. Passing null or an empty string resets filteredItems to the full _items list. When at least one item is selected the footer shows a block rng-button labelled "Clear filters" that calls clearFilters() - it resets both signals to the original items() input and emits { type: 'clear', payload: selectedItems }. On open the popover emits IPopoverChangeEvent with type: 'open' and the component focuses the search input via viewChild(SearchInputComponent).

Heads up

Type in the search box after opening the popover - e.g. act matches Active and Inactive. Use Clear filters in the footer to reset all selections at once.

Disabled state

When [items] is an empty array the trigger computes isDisabled() === true and renders with rng-button--disabled. Provide at least one item to enable the filter.

Status Disabled - items is empty (isDisabled() === true).
