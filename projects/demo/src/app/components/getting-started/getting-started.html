Getting Started

@im4all/roolith-ng is a standalone Angular component library - no NgModule, tree-shakable with sideEffects: false. Install it from npm, add the SCSS tokens, and import the components you need.

At a glance

Published as @im4all/roolith-ng on npm - standalone components, SCSS design tokens, and overlay primitives for Angular 21+.

Prerequisites

Make sure your project meets the peer requirements before installing:

RequirementVersionNotes
Angular>=21.0.0@angular/core, @angular/common, @angular/forms
Node.js>=20.11 or 22+Required by Angular 21
TypeScript~5.9As shipped with Angular 21

Runtime dependencies lodash-es, luxon and tslib are installed automatically with the package - you do not need to add them manually.

Installation

Install the package with your preferred package manager:

Peer dependencies

If your project was created with Angular 21, @angular/core, @angular/common and @angular/forms are already present. No extra install is needed - npm / yarn / pnpm will warn only if they are missing.

Add styles

Add the global tokens and component styles once - typically in src/styles.scss:

This includes base styles, resets, typography, layout and all component modules via rng-everything() from @im4all/roolith-ng/sass/rng-scss. See projects/roolith-ng/src/sass/rng-scss.scss:77 for the full mixin.

Modular import

Need less CSS? Import only what you use instead of rng-everything():

Override brand tokens at runtime with CSS variables - no rebuild or SCSS fork needed:

Every component reads the --rng-* tokens (e.g. --rng-color-primary, --rng-border-radius). Details and dark-mode tokens are on the Theming page.

Usage

Every component is standalone - import only what you need:

Verify the install by rendering a component in your app:

  • Prefix is rng - e.g. <rng-button>, <rng-card>, <rng-table>.
  • All components are tree-shakable - unused components are removed from the build.
  • No global registration or NgModule import required.

Forms

Inputs work with both ReactiveForms and ngModel. Import ReactiveFormsModule or FormsModule as needed:

Example: <rng-text-input formControlName="email" placeholder="Email" /> or <rng-select-input [data]="options" [(value)]="selected" />. Validation, disabled and error states are built in.

Theming

Design tokens ship as SCSS variables and CSS custom properties under --rng-*. Override a variable before the mixin or set the CSS variable at runtime - every component follows.

Heads up

See Theming for the full token list, dark mode with .theme-dark, and brand customization patterns.
