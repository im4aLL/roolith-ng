Multi Select

A multi-value select input built as rng-multi-select-input. Selected items appear as removable chips inside the field with an overflow badge when the limit is exceeded. Supports search filtering, keyboard navigation, typeahead, custom option templates, Select All / Deselect All, and FormValueControl<IMultiSelectInputOption[]> integration for signals forms.

Import

IMultiSelectInputOption

Each option has a label for display and a value for identity. Optional icon and subtext are used by the custom template and the default template.

Usage

Basic

Provide [data], label and placeholder. Bind [(value)] for two-way sync - value is a model<IMultiSelectInputOption[]>. Clicking the field calls onInputFocusHandler() which shows focus and the dropdown via isActive(). Clicking an option toggles it via onSelectHandler(item) and removes a chip via onRemoveChip(item, $event).

Searchable (filtering)

Set [searchable]="true" to render a text <input> inside the field. The option list is filtered via the filteredData computed which does a case-insensitive label.includes() on inputValue(). When searchable is false the component instead buffers keystrokes and focuses the first matching option (typeahead, 300ms debounce) via _watchForTypeahead.

Hint

Provide hint to show helper text below the field. It renders via hintMessage() when not overridden by an error.

Selected: {{ hintSelected().length }} item(s)

Error state

Set [error]="true" to apply error styling via rng-input--error. When errorMessage is provided it overrides hint in the hint area via the computed hintMessage().

Use errorMessage to replace the hint when invalid - otherwise hint is shown. Current: {{ errorSelected().length > 0 ? errorSelected()[0].label : 'none' }}

Limit visible chips (maxChipsShown)

By default maxChipsShown is 5 (see maxChipsShown = input<number>(5)). Only visibleChips() (value().slice(0, maxChipsShown())) are rendered. When remainingCount() is greater than 0 a badge "N more selected" is shown.

Showing {{ maxChipsSelected().length }} selected with default limit - badge shows {{ maxChipsSelected().length > 5 ? (maxChipsSelected().length - 5) + ' more selected' : 'no overflow' }}.

With [maxChipsShown]="2": selected {{ maxChipsSelected2().length }} @if (maxChipsSelected2().length > 2) { - badge: {{ maxChipsSelected2().length - 2 }} more selected }

Pre-filled 5 items with maxChipsShown=2 renders 2 chips + "3 more selected".

Select All / Deselect All

Set [allowSelectAll]="true" to show Select all and Deselect all buttons at the top of the dropdown via rng-input-list__item--select-all. onSelectAllHandler() sets value to all items in data (not just the filtered subset). onDeselectAllHandler() clears value. Both clear inputValue and re-focus the input.

@if (selectAllSelected().length > 0) { Selected {{ selectAllSelected().length }} / {{ countries.length }}: @for (item of selectAllSelected(); track item.value) { {{ item.label }}@if (!$last) { , } } } @else { Use Select all inside the dropdown to pick all countries. }

Custom option template

Use #rngMultiSelectInputOptionTemplate with let-item to customize each option row. By default it shows item.icon as <i [class]="item.icon"> with the label and a check when selected. For flags, put the CDN URL in icon (e.g. https://flagcdn.com/w20/us.png) and render it as <img [src]="item.icon"> next to rng-input-list__item-content.

States

Use [disabled]="true" to disable the field via rng-input--disabled and native [disabled], [readonly]="true" for read-only, [required]="true" for ARIA required via aria-required, [rightAligned]="true" to align the dropdown to the right edge via rng-input-list--right, [dropdownWidth] to set min-width in pixels on the list, and name to set the native name attribute.

Right aligned: {{ rightAlignedSelected().length }} | Width 320: {{ dropdownWidthSelected().length }} | Name: {{ nameSelected().length }} (name="countries")

Two-way binding and valueChange

Bind [(value)] for two-way sync or listen to (valueChange) for explicit handling. The value model is a model<IMultiSelectInputOption[]>. Selecting an option toggles it, removing a chip calls onRemoveChip which stops propagation and filters the value.

Current: {{ twoWaySelected().length }} item(s) @if (twoWaySelected().length > 0) { - @for (item of twoWaySelected(); track item.value) { {{ item.label }}@if (!$last) { , } } }

Keyboard and overlay behavior

The field is focusable via tabindex="0" and opens on click and keydown.enter. While open, ArrowUp / ArrowDown cycle focus through options (wrapping), Escape calls hideOptions(), and document:click outside the component calls removeFocus().hideOptions(). The dropdown position flips to the top when there is insufficient space below, via _calculateListPosition() which checks window.innerHeight - inputRect.bottom against list.offsetHeight and sets isShowListOnTop() to toggle rng-input-list--top.

With FormField (signals forms)

rng-multi-select-input implements FormValueControl<IMultiSelectInputOption[]> and can be bound to a signals form via [formField]. The component syncs value, disabled, required, invalid, touched and validation state from the form.
