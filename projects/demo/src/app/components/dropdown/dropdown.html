Dropdown

Displays a menu to the user - such as a set of actions or functions - triggered by a button. Wire a trigger element with [rngDropdownTarget] to the matching name of rng-dropdown. The dropdown is rendered as a native popover anchored via anchor-name: --rng-<name> and auto-positions to avoid viewport overflow. Supports grouped items with optional headline, per-item icon, a secondary slot via secondaryLabel or secondaryIcon, plus isDanger and isDisabled states.

Wiring trigger and panel

Place rngDropdownTarget="<name>" on a wrapper element that contains the trigger button. The directive finds the first clickable element inside the wrapper and sets popovertarget="rng-dropdown-<name>", the rng-dropdown__trigger class and anchor-name: --rng-<name> automatically. The name input on rng-dropdown must match exactly. The panel itself renders with id="rng-dropdown-<name>", popover and --rng-dropdown-anchor: --rng-<name>.

Secondary label and secondary icon

Use secondaryLabel to render text in the right slot, or secondaryIcon to render an icon there. The secondary content renders inside rng-dropdown__item-secondary and secondaryIcon takes precedence over secondaryLabel when both are set. Typical uses are keyboard shortcuts (secondaryLabel: 'Ctrl + k') or status checks.

Set isDisabled: true on an item to render it with rng-dropdown__item--disabled. Disabled items are still visible but are muted and do not emit itemClick - onItemClick returns early when isDisabled is true. They still render icons and secondary content if provided.

Fixed alignment

By default the dropdown auto-detects viewport overflow on the native toggle event (when newState === 'open') and applies the correct position class. Pass alignment to force a fixed position and skip that detection entirely - useful when the trigger is near a viewport edge.

Auto-detection when alignment is null checks the bounding rect against window.innerWidth and window.innerHeight inside a setTimeout and sets one of: rng-dropdown--right, rng-dropdown--top or rng-dropdown--top-right, or no class when there is sufficient space.

Custom content via ng-content

For fully custom markup omit [groups] and project content directly. The component renders groups when groups().length > 0 and always projects <ng-content /> after it. Use the same class names (rng-dropdown__body, rng-dropdown__group, rng-dropdown__list, rng-dropdown__item) to match the built-in styling.

Position (auto-detection)

When alignment is null (the default) the dropdown listens to the native toggle event. On open it measures its getBoundingClientRect() against window.innerWidth / window.innerHeight and sets the appropriate class. On close it resets the position class to null. When a fixed alignment is set, that logic is skipped.

ConditionClass applied
Sufficient space below and to the right(none)
Would overflow the right edgerng-dropdown--right
Would overflow the bottom edgerng-dropdown--top
Would overflow both bottom and right edgesrng-dropdown--top-right

rngDropdownTarget Directive

Applied to the wrapper element of the trigger. The directive targets the first child element (or the element itself when it is a <button> / <a>) and automatically sets all required Popover API attributes.
