Text Input

A single-line text input built as rng-text-input. Supports input type variants (text, password, email, hidden), validation via minLength, maxLength and pattern, plus label, hint, placeholder and FormValueControl<string> integration for signals forms. The current value is exposed as string via [(value)] and (valueChange) (empty string when empty).

Import

Usage

Basic

Provide label, optionally placeholder and hint. Use two-way binding [(value)] to sync the string value. When the field is empty the model is '' - otherwise the typed string.

Value: "{{ basicValue() }}" ({{ basicValue().length }} chars)

Placeholder

Use placeholder to show hint text when the value is ''. It is forwarded to the native placeholder attribute on <input>.

Full name value: "{{ placeholderNameValue() }}"

Email value: "{{ placeholderEmailValue() }}"

Type variants

Use [type] to set the native type. Supported values are 'text' (default), 'password', 'email' and 'hidden'. The value is forwarded to [type] on <input> and hidden hides the field visually while keeping the model.

Text: "{{ typeTextValue() }}"

Password: {{ typePasswordValue().length > 0 ? '•'.repeat(typePasswordValue().length) + ' (' + typePasswordValue().length + ' chars)' : 'empty' }}

Email: "{{ typeEmailValue() }}"

Hidden input (not visible)

Hidden value: "{{ typeHiddenValue() }}" - rendered as <input type="hidden"> with no label or hint.

Hint

Provide hint to show helper text below the field via rng-input__hint. The hint is visible when not overridden by an error message.

Value: "{{ hintValue() }}"

Error state

Set [error]="true" to apply error styling via rng-input--error. When errorMessage is provided it overrides hint in the hint area via the computed hintMessage().

Use errorMessage to replace the hint when invalid - otherwise hint is shown. Current: "{{ errorValue() }}"

States

Use [disabled]="true" to disable the field via rng-input--disabled and native [disabled], [readonly]="true" to make it read-only via [readonly], [required]="true" for ARIA required via aria-required, and name to set the native name attribute. The component also reflects aria-invalid when invalid() or error() is true.

Read-only: "{{ readonlyValue() }}" | Required: "{{ requiredValue() }}" | Name: "{{ nameValue() }}" (name="fullName")

Validation - minLength, maxLength and pattern

Use [minLength] and [maxLength] to constrain character count and [pattern] with an array of RegExp for regex validation. These map to signals forms validation - pattern() is a readonly RegExp[] (default []). Combine them with hint to guide the user and with error / errorMessage for server or manual errors.

Value: "{{ minLengthValue() }}" ({{ minLengthValue().length }} chars) | needs 3+

Value: "{{ maxLengthValue() }}" ({{ maxLengthValue().length }}/20)

Pattern: /^[a-zA-Z\s]+$/ | Value: "{{ patternValue() }}" @if (patternValue() && !cityPattern.test(patternValue())) { - fails pattern }

Combined: "{{ combinedValidationValue() }}" ({{ combinedValidationValue().length }} chars) | pattern /^[a-zA-Z0-9]+$/

Two-way binding and valueChange

Bind [(value)] for two-way sync or listen to (valueChange) for explicit handling. The value model is a model<string> with default ''. Typing in the field sets value via (input)="value.set($event.target.value)" and blurring marks touched as true.

Current: "{{ twoWayValue() }}" ({{ twoWayValue().length }} chars)

With FormField (signals forms)

rng-text-input implements FormValueControl<string> and can be bound to a signals form via [formField]. The component syncs value, disabled, required, invalid, touched and validation state from the form.

Full example

Combining label, placeholder, hint, type variants and live value display.

Full name: "{{ fullNameValue() || 'empty' }}" | Email: "{{ fullEmailValue() || 'empty' }}" | Password: {{ fullPasswordValue().length > 0 ? '•'.repeat(fullPasswordValue().length) : 'empty' }}

Behavior notes

  • Typing updates value immediately via (input)="value.set($event.target.value)" - the native <input> value is bound with [value]="value()".
  • Blurring the field marks touched as true via (blur)="touched.set(true)".
  • The outer wrapper uses rng-input with rng-input--disabled and rng-input--error modifiers.
  • Validation inputs minLength, maxLength and pattern are consumed by signals forms - they do not add native HTML validation attributes.
