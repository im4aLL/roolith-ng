Pagination

A pager for large data sets built as rng-pagination. Renders Previous / Next controls, numbered page buttons with ellipsis (null gaps) and a meta area with a rows-per-page selector and info text. The component hides itself when total is 0 and hides the page navigation when everything fits on one page while keeping the selector and info visible.

Import

Usage

Basic

Pass total and bind the active page via [selectedPageNumber]. Listen to (changeEvent) and set the new page from event.page. With the defaults (perPage 10, maxPageItem 10) a total of 120 yields 12 pages.

Current page: {{ basicPage() }} of {{ basicTotalPages() }} • Total: {{ basicTotal() }}

Custom page size and max visible pages

Set [perPage] to change the initial rows per page (one of 5 | 10 | 15 | 20 | 25 | 50 | 100). Set [maxPageItem] to control how many numbered buttons are shown at once. When the page count exceeds maxPageItem the component collapses middle pages with an ellipsis (rng-pagination__item--break with rng-icon--more).

Current page: {{ customPage() }} • perPage 25 • maxPageItem 5 • Total pages: {{ customTotalPages() }}

Ellipsis generation

Page numbers are produced by _generatePageNumbers(). When totalPages <= maxPageItem all pages are shown. Otherwise the first and last page are always kept, the window around currentPage is centered, and gaps are rendered as null entries. Example with 10 pages and maxPageItem 10 is never collapsed; with maxPageItem 5 a middle page like 5 renders as [1, null, 4, 5, 6, null, 10] or similar.

Handling all event types

(changeEvent) emits IPaginationEvent with type set to 'pageChange', 'nextPage', 'previousPage' or 'pageSizeChange'. Page events carry page; pageSizeChange carries rowsPerPage and resets to page 1. The component calls preventDefault() on the underlying anchor clicks - update your state in the handler and reload data.

Visibility rules

The top-level @if (total() > 0) in the template means nothing renders when total 0. When totalPages <= 1 the computed isShowPagination() is false so rng-pagination__list (Previous, page buttons, Next) is hidden but the meta row is still shown. The meta row contains the rng-select-input for rows per page and infoText() which reads "Total records X. Showing page Y out of Z.".

Not rendered (total 0)

No output - container is empty when total 0. Inspect to see no rng-pagination element.

Single page (total 8, perPage 10) - navigation hidden, meta visible

Styling notes

The host renders rng-pagination with rng-pagination__list for the navigation and rng-pagination__meta for the selector and info. Page buttons use rng-button rng-button--ghost normally and rng-button--gray for the active page. Ellipsis uses rng-pagination__item--break with rng-icon--more. Previous and Next use rng-icon--arrow-left and rng-icon--arrow-right. The selector area uses rng-pagination__selector, rng-pagination__selector-label, rng-pagination__selector-field and the info uses rng-pagination__info.
