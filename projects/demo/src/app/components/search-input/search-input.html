Search Input

A search field built as rng-search-input. Emits the input value via a debounced debouncedChange output (default 250ms) with distinctUntilChanged, shows a clear button when a value is present, and exposes the current query as a string | null model via [(value)]. It does not implement FormValueControl - it is intended as a standalone UI search control.

Import

Usage

Basic

Listen to (debouncedChange) to react to the debounced query. The output is backed by outputFromObservable(toObservable(value).pipe(debounceTime(debouncedTime()), distinctUntilChanged())) and emits only after the configured delay. Typing updates value immediately via onInput but the output waits for the debounce.

Type to see the debounced output after 250ms - duplicate consecutive values are ignored via distinctUntilChanged.

Two-way binding

Bind [(value)] for immediate two-way sync or use (valueChange) for explicit handling. The value model is a model<string | null> with default null - empty input syncs as '' after typing.

Debounce timing

Use [debouncedTime] to configure the debounce delay in milliseconds. Default is 250. Set to 500 for a slower search or 0 to disable debouncing and emit on every keystroke. The debounced pipeline also applies distinctUntilChanged so duplicate consecutive values do not re-emit.

With 0 the debounced output emits immediately - compare typing speed with the 500ms field above.

Disabled

Set [disabled]="true" to disable the field. The component adds rng-input--disabled to the wrapper and forwards [disabled] to the native <input>.

Disabled value: {{ disabledValue() === null ? 'null' : '"' + disabledValue() + '"' }}

Clear button

The clear button (rng-input__search-clear-button with rng-icon--close) appears automatically when isShowClearButton() is true. Typing a non-empty value via onInput sets the flag to true, clearing via clearInput() resets value to '', hides the button and resets the native input value via inputElement().

Value: {{ clearableValue() === null ? 'null' : '"' + clearableValue() + '"' }} - type to show the clear button, click it to reset to ''.

Focus method

Call focus() on the component instance to programmatically focus the native <input> via inputElement(). The method guards against a missing element and is a no-op when inputElement() is undefined.

Notes

  • Does not implement FormValueControl - use as a standalone UI control, not with [formField].
  • The outer wrapper uses rng-input rng-input--search with a leading rng-icon--search icon and an optional rng-input__search-clear-button.
  • Debounced output uses distinctUntilChanged - typing the same value consecutively does not re-emit.
