Breadcrumb

Displays the path to the current resource using a hierarchy of links. Each item is rendered as an <a> with href from link (falls back to # when omitted). The last item in data is automatically styled as active.

Import

Usage

Basic

Pass an array of IBreadcrumbItem to [data]. The last entry has no link and is rendered as the active (current) page.

With explicit links

Every item except the current page typically has a link. Links can be absolute paths, hash fragments or full URLs handled by your click handler.

Without link (fallback)

When link is omitted the anchor falls back to href="#". This is intentional for the active/current item - you still receive the item in clickEvent if the user clicks it, but no navigation occurs by default.

Listening to click events

clickEvent fires for every item click and emits the full IBreadcrumbItem. The component calls event.preventDefault() internally so no browser navigation happens - handle routing in your callback (e.g. with Router.navigateByUrl).
