Message

An inline feedback banner for contextual notices, form hints and alerts. Supports default, success, danger, warning, info and primary type variants, an optional showClose button and a custom icon override. Content is projected via <ng-content> - pass any text or HTML as children. When the close button is clicked the message hides with is--hidden and emits closeEvent.

Import

Usage

Basic

The default message with neutral styling and an info icon fallback. Use it for generic contextual feedback.

Lorem ipsum dolor, sit amet consectetur adipisicing elit. Accusamus eaque doloremque sequi excepturi iste illo saepe enim ducimus natus? Enim ipsam nisi unde, reprehenderit quas provident. Nisi tenetur possimus recusandae.

With close button

Add a dismiss button with [showClose]="true". The button renders as rng-button with variant="dark" and size="xsmall" inside rng-message__close. Clicking it sets the internal isShow signal to false, adds is--hidden and emits closeEvent.

Lorem ipsum dolor, sit amet consectetur adipisicing elit. Accusamus eaque doloremque sequi excepturi iste illo saepe enim ducimus natus? Enim ipsam nisi unde, reprehenderit quas provident. Nisi tenetur possimus recusandae.

Heads up

The message does not remove itself from the DOM - it only hides with is--hidden. To fully remove it, conditionally render it with @if or re-create the instance after closeEvent. See the dismissible example below for a reset pattern.

Type variants

Set type to change the visual variant and the default icon. The mapping is success -> check, danger -> alert and warning / info / primary / default -> info when no icon is provided. The type also controls the host class rng-message--{type} - default renders no modifier class.

Success - your changes were saved successfully. Danger - there was a problem processing your request. Warning - please review the information before continuing. Info - a new update is available for your workspace. Primary - welcome to the new dashboard experience. Default - this is a neutral contextual message.

Custom icon

Override the default icon with icon. Any IconNameType is accepted - the component renders rng-icon--{icon} inside rng-message__icon. The icon is computed by iconClassName() which prefers the explicit icon input over the type mapping.

Styling and behavior notes

The host element renders rng-message with an optional modifier rng-message--{type} from messageClassName(). The icon is rng-icon rng-message__icon plus iconClassName(). The close wrapper is rng-message__close and contains a small dark rng-button. When isShow() is false the host adds is--hidden - the element stays in the DOM. Provide a custom icon to override the type-based default.
