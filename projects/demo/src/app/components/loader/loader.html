Loader

A global overlay for async operations and a lightweight inline spinner. rng-loader is controlled by LoaderService and covers the viewport - blocking by default or non-blocking when requested. rng-inline-loader is a self-contained spinner for buttons, cards, table cells and other inline contexts.

Import

Setup

Root loader host

Place <rng-loader /> once in your root layout template (e.g. app.component.html) so it is globally available. The component reads LoaderService.isLoading(), isNonBlocking() and message() and renders the overlay when needed. Without the host, calls to LoaderService.show() will update the signals but nothing will appear.

Injecting the service

Inject LoaderService in any component or service to control the loader. The service is providedIn: 'root' so no extra provider is needed.

Usage

Blocking loader (default)

Covers the full viewport and blocks user interaction. The overlay uses rng-loader with rng-loader__content, rng-loader__icon and rng-loader__text. The icon renders rng-icon--spinner when blocking. Default message is 'Processing...'. Call hide() to dismiss and reset all state.

Blocking loader with custom message

Pass a string to show(message) to override the default text. The message is rendered inside rng-loader__text. When no message is stored the component falls back to 'Processing...'.

Non-blocking loader

Displays the loader without blocking interaction. showNonBlocking() sets isNonBlocking to true which adds rng-loader--non-blocking to the overlay. The icon switches to rng-icon--loader. The user can still interact with the page while the loader is visible.

Non-blocking loader with custom message

Same as above but with a custom string: showNonBlocking('Loading data...'). Default is still 'Processing...' when omitted.

Usage in an async operation

Wrap the operation in show() / hide() with a try / finally so the loader always clears even when the request fails. Use showNonBlocking instead if the UI should remain interactive.

Simulate async (2s)

Hide is blocked during active HTTP requests

hide() is a no-op while _activeRequests > 0 (incremented by startRequest() and decremented by endRequest() from the global loading interceptor). Internal _hide() resets isLoading, isNonBlocking and message. For manual flows with no interceptor, hide() clears the overlay immediately.

Inline Loader

rng-inline-loader is a lightweight, self-contained spinner for use inline within UI elements such as buttons, cards or table cells. It does not depend on LoaderService - just drop it in the template. Content projection overrides the default Loading... text, and the spinner renders rng-inline-loader with rng-icon--loader rng-spinner.

API

LoaderService Methods

MethodSignatureDescription
showshow(message?: string): voidShows the blocking loader. Sets message, isNonBlocking to false and isLoading to true. Default message: 'Processing...'
showNonBlockingshowNonBlocking(message?: string): voidShows the non-blocking loader. Sets isNonBlocking to true and isLoading to true. Default message: 'Processing...'
hidehide(): voidHides the loader and resets all state. No-op while _activeRequests > 0. Delegates to internal _hide() which clears isLoading, isNonBlocking and message
startRequeststartRequest(): voidIncrements the active request counter and shows the non-blocking loader. Called by the global loading interceptor
endRequestendRequest(): voidDecrements the active request counter and hides the loader when no requests remain. Called by the global loading interceptor

LoaderService Signals (readonly)

SignalTypeDescription
isLoadingSignal<boolean> (readonly)Whether the loader is currently visible
isNonBlockingSignal<boolean> (readonly)Whether the loader is in non-blocking mode - adds rng-loader--non-blocking
messageSignal<string | null> (readonly)The current loader message. rng-loader falls back to 'Processing...' when null

rng-loader

SelectorDescription
rng-loaderGlobal overlay. Renders rng-loader with rng-loader__content, rng-loader__icon and rng-loader__text. Adds rng-loader--non-blocking when isNonBlocking() is true. No inputs - all state comes from LoaderService

rng-inline-loader

SelectorDescription
rng-inline-loaderInline spinner. Renders rng-inline-loader with rng-icon--loader rng-spinner and projects <ng-content> with default Loading...

rng-inline-loader Content Projection

SlotDescription
(default)Text or markup displayed next to the spinner. Defaults to Loading... when nothing is projected

Styling notes

rng-loader is a fixed fullscreen overlay. rng-loader--non-blocking relaxes pointer-events so the page remains interactive. rng-inline-loader is inline-flex with a spinning icon - use it inside buttons, cards or table cells without any service wiring.
