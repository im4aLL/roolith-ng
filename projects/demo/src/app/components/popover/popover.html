Popover

A floating panel anchored to a trigger element via the native popover API. Wire a trigger element with [rngPopoverTarget] to the matching name of rng-popover. The popover is rendered with popover and position-anchor: --rng-<name> and auto-positions to avoid viewport overflow. Supports an optional header and subtext as plain strings or rich <ng-template> projection via #rngPopoverHeader and #rngPopoverSubtext, any body markup through the default slot, and a changeEvent that emits 'open' | 'close'.

Wiring trigger and panel

Place rngPopoverTarget="<name>" on a wrapper element that contains the trigger button. The directive finds the first clickable element inside the wrapper and sets popovertarget="rng-popover-<name>", the rng-popover__trigger class and anchor-name: --rng-<name> automatically. The name input on rng-popover must match exactly. The panel itself renders with id="rng-popover-<name>", popover and --rng-popover-anchor: --rng-<name>.

Rich body content

Everything without a template selector is projected into rng-popover__content via <ng-content />. The content wrapper adds rng-popover__content--spacing only when a header or subtext is present. Use it for lists, actions, or any custom layout. You can include a close button that calls closePopover() on the popover instance.

Got it

Fixed alignment

By default the popover auto-detects viewport overflow on the native toggle event (when newState === 'open') and applies the correct position class. Pass alignment to force a fixed position and skip that detection entirely - useful when the trigger is near a viewport edge.

Right

Always opens to the right via rng-popover--right.
Top

Always opens above via rng-popover--top.
Top Right

Always opens above and to the right via rng-popover--top-right.

Auto-detection when alignment is null checks the bounding rect against window.innerWidth and window.innerHeight inside a setTimeout and sets one of: rng-popover--right, rng-popover--top or rng-popover--top-right, or no class when there is sufficient space.

alignment CSS class When to use
(not set) auto-detected Default - let the component decide
'right' rng-popover--right Trigger is near the right edge
'top' rng-popover--top Trigger is near the bottom edge
'top-right' rng-popover--top-right Trigger is in a bottom-right corner

Listening to open and close events

changeEvent is emitted from two places: a native toggle listener registered in ngAfterViewInit and the (toggle) handler onToggle. Both emit { type: 'open' | 'close' }. Use it to sync state, fire analytics or lazily load content when the popover opens.

Outside clicks and Escape still close the popover natively and emit changeEvent with type: 'close'.

Position (auto-detection)

When alignment is null (the default) the popover listens to the native toggle event. On open it measures its getBoundingClientRect() against window.innerWidth / window.innerHeight inside a setTimeout and sets the appropriate class. On close it resets the position class to null. When a fixed alignment is set, that logic is skipped.

ConditionClass applied
Sufficient space below and to the right(none)
Would overflow the right edgerng-popover--right
Would overflow the bottom edgerng-popover--top
Would overflow both bottom and right edgesrng-popover--top-right

API

rngPopoverTarget Directive

Applied to the wrapper element of the trigger. The directive targets the first child element (or the element itself when it is a <button> / <a>) and automatically sets all required Popover API attributes.
